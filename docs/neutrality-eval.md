# 行为盲测：skill 到底有没有在规定风格

> **需要重跑。** 下面的结果测的是 film-core 重构之前的套件（入口 film-production，research / storyboard 还是两个 skill）。
> 重构把 film-production 并进 film-core、research + storyboard 合成 film-story，入口文案和流程说明都换了——
> 这份结论对现在的套件不再作数，按「怎么复现」用新入口重跑一遍再引用。

`dev/selfcheck.mjs` 只能做**词法**检查——它能抓到"默认配色"四个字，抓不到
"模型读完这套 skill 之后，是不是每次都画出同一种东西"。
后者才是这套东西要防的病，而它只能用行为测。

`film-storyboard` 自己在 VERIFIED.md 里承认了这个缺口：

> 这次是我自己跑自己的流程，写判据时就知道要防网格，有自证偏差。
> 没测一个没读过 VERIFIED.md 的新模型拿到新主题时会不会照样写出候选 0 并杀掉它。

这份文件补上它。

## 设计

四个**全新**的 agent，没有这个会话的任何上下文，不知道网格那段历史，
也没被告知"要防什么"：

| 组 | 主题 | 条件 |
|---|---|---|
| A1 | 为什么深海鱼长得那么奇怪（具象） | 读 `film-production` 入口，按 skill 流程走 |
| A0 | 同上 | **对照组**：不给 skill，只说"用代码渲染的程序动画" |
| B1 | 一笔钱在银行间清算系统怎么走（抽象） | 读 `film-production` 入口 |
| B0 | 同上 | **对照组** |

都只做到"确定视觉方案"就停，不实现——因为失败恰恰发生在这一步。

## 判据（在看到 A1/B1/B0 结果之前写下）

写在前面：**这个测试可能证伪我自己的主张。** 如果带 skill 的两组产出了
容器、或者和对照组没有可辨别的差别，那就是 skill 没起作用，要如实写。

1. **容器检查（最硬的一条）**：选定的方案，换个主题还成不成立？
   能装任何主题的（网格、卡片列表、时间轴、两条竖线加箭头的时序图）是容器。
   - 带 skill 的组出现容器 → **skill 失败**。
2. **互异性**：A1 和 B1 的方案是否映射到**不同类**的视觉变量
   （物质/空间/时间/文字/视角/力）？同类换皮不算不同。
   - 两组落在同一类 → skill 的发散不起作用。
3. **相对对照组的增量**：带 skill 的方案是否比对照组更不容器、或淘汰过程更可查？
   - **如果对照组同样好，就如实写"这个主题上 skill 没有增量"。**
     对照组是 Opus，不是弱模型，它本来就可能给出好方案。
4. **留痕**：带 skill 的组有没有产出 `docs/mechanism.md`、写下候选 0
   （本题的默认画法）并让判据杀死它？
   - 没留痕 → 流程没被真正执行，只是读了一遍。

## 怎么复现

改过任何 skill（尤其 `film-story` 和 `film-core`）之后重跑一遍。
四个 agent 必须是**全新上下文**，不能是改 skill 的那个。prompt 原样如下，
**不要**在里面提网格、提失败史、提"要防什么"——那会污染测试。

**带 skill 组**（`<主题>` 和 `<slug>` 换掉）：

> 在 <repo> 下，为下面这个主题设计一支片子的视觉方案。
>
> **主题：\<主题\>。** 15 秒，9:16 竖版，面向普通观众。
>
> 这个仓库里有一套做视频的 skill（`skills/film-*/`）。**先读 `skills/film-core/SKILL.md`**，它是入口，会告诉你整条流程和每一步该读哪个 skill。按它说的做。
>
> 你**只需要做到"确定视觉方案"这一步就停**，不要写 `scene.html`、不要渲染、不要合成音频。产出是 `films/<slug>/docs/` 下的文档。
>
> 限制：只在 `films/<slug>/` 里写文件，别动 `skills/` 和别的片子。不要再派 subagent。20 分钟预算。
>
> 汇报：你最后选定的视觉方案是什么（一两句话说清楚画面靠什么承重）、你考虑过并淘汰了哪些方案、淘汰的理由。

**对照组**：同样的主题，去掉所有关于 skill 的句子，只保留
"片子是用代码（canvas / WebGL）渲染出来的程序动画，不是实拍也不是逐帧手绘"
和产出路径，其余一致。

题目要一具象一抽象，而且**换题**——同一道题跑第二遍只会测到记忆。

## 这个设计的局限（核实 B1 时发现的，必须写下）

**带 skill 组不是盲的。** 我没在 prompt 里提过网格，但 `film-storyboard/SKILL.md`
开头就讲了那段失败史，所以读了 skill 的 agent 一定知道。B1 的原文就暴露了这一点：
它写"不用格线——因为账本天然是表格，表格就是网格，而**网格是这套管线的已知默认容器**"。

所以这个测试能证明的是：**skill 把教训传递出去了，而且传递得足够具体，
能让一个新模型在一个全新主题上主动预判它。**
它**不能**证明：模型在不知道这个陷阱的情况下会自己避开。

对照组才是真盲的。两边的不对称是设计上的，不是缺陷——
"把教训可靠地传下去"正是 skill 存在的理由。但结论必须按这个边界写，
不能说成"skill 让模型变得更有创意"。

要测后者得换个设计：拿一个 skill 里**没写过**的失败模式去测，
而不是拿它开宗明义就讲的那个。这一轮没做。

## 结果

### 结论（四组齐了之后写）

**判据 1 容器检查：四组都不是容器。** 带 skill 的两组没有出现容器——
但对照组同样没有。**我原来的框架是错的。**

我以前把那两支失败的片子归因为"模型会默认退回网格"。四组盲测里，
**两个完全不知情的对照组都给出了真机制**（A0「深度同时驱动光照衰减与形态畸变」、
B0「能移动的只有指令，钱是位置锁死的柱子」）。所以网格不是模型的天性，
**是旧 skill 诱导出来的**——旧 `motion-reel` 的分镜示例就是"48 块错峰弹入拼成网格"，
旧 spec 模板要求"把故事拆成 8–12 个 UI 状态"。`film-storyboard` 的诊断
（"示例比警告更有约束力，模型抄示例不抄警告"）是对的，我的归因是错的。

这改变了新 skill 的价值主张：它的作用不是"拦住一个本来会犯的错"，
而是**不去诱导它**，外加下面这些可追溯的增量。

**判据 2 互异性：通过。** A1 落在「光/物质」类（反射率 × 当下的阳光），
B1 落在「文字 + 视角」类（被改写的那一行数字 + 镜头的嵌套穿越）。不同类。

**判据 3 相对对照组的增量：有，但不是"点子更好"，是四件具体的事。**

最干净的一处对照：**A1 写下并杀死的候选 0 是"深度就是一根竖向标尺，
每到一层侧面弹出一张怪鱼卡片 + 标签"——而 A0 对照组真的做了一根深度计贴在屏幕右侧。**
对照组保留了带 skill 组明确判为容器并扔掉的那套装置。

| | 对照组 | 带 skill |
|---|---|---|
| **克制** | A0 有深度标尺 + 下沉镜头 + 连续变形的鱼；B0 仍有一道光在两点间跑 | A1 去掉标尺和镜头移动，深度只靠光变；B1 写死"画面里不允许任何东西在两行之间运动" |
| **机制的边界** | 不写 | A1 明确写出机制演不了什么："食物少所以嘴大"不是光学现象，画面演不出来，只能靠旁白交代 |
| **事实接地** | A0 把"水滴鱼反转"当备选，没指出归因问题 | A1 把"压强致怪"登记为 `N01 否决`，理由是 NOAA/MBARI 都归因于光与食物，并注明"留着这条防止下次写进去" |
| **可查的淘汰** | 有理由，但不成体系 | 候选 0 + 去名词骨架 + 三刀逐条，`factcheck.mjs` 实跑（B1 0 错 0 警，A1 0 错 1 警） |

B1 还主动预判了这套管线自己的失败模式：
"账本天然是表格，表格就是网格，而网格是这套管线的已知默认容器"——所以禁了格线。

**判据 4 留痕：通过。** 两组都写了候选 0 并让判据杀死它，不是回避。
两组都产出了 `memory-snapshot.md`（搜索前的记忆快照），说明 `film-research`
的流程被真执行了。A1 还记下一条记忆纠错："我原以为红光几米到十几米就没了，
NOAA 原文写的是 100 米处红光不穿透"。

**两组都如实报了自己的短板**：A1 说 WHOI 页面被本机 TLS 拦截打不开、
NOAA 一篇日志 404，这两条只用了搜索摘要、没算已核；还说旁白草稿 65 字对 15 秒偏紧，
并预先写了删哪一句。B1 说 `shotlist.md` 还是空骨架，因为按流程要等 `narration.json`
实测时长才能排时间——**它没有手填秒数去凑一份好看的分镜**。

### 一句话

skill 不规定风格这件事，**词法上由 `selfcheck.mjs` 守，行为上由这次盲测证实**：
两个全新模型在两个差异极大的主题上，产出了互不相同、也不同于对照组的方案，
而且增量能逐条追溯到具体的 skill 机制。

但要按边界说话：**它证明的是"教训被可靠地传下去了"，不是"模型变得更有创意"**
（见上一节的局限），而且**"模型会默认画网格"这个前提本身被证伪了**。

以下是四组的原始记录，按回来的顺序。

### A0 · 对照组 · 深海鱼（不带 skill）

选定「下沉即变形」：一条鱼沿竖屏下沉，深度**同时**驱动两件事——
按深度对 RGB 三通道分别衰减（红光最先消失，所以"变红即隐身"是光照算出来的，
不是另做的动画），以及鱼的形态参数（眼、诱饵光、下颌角、牙、胃）随深度连续变化。
淘汰了手电筒揭秘、图鉴标注卡、水滴鱼反转、能量仪表、多物种快剪、上下双栏对照。

**按判据 1 评：这不是容器。** 「深度驱动光照衰减 + 形态畸变」换成讲交子或 TLS 都不成立。
**按判据 4 评：它自发写下了淘汰过程**，虽然没有候选 0 的概念。

这是一个强对照组。先记在这里，不等别的结果再改口。

### B0 · 对照组 · 银行间清算（不带 skill）

选定一条铁律：**能移动的只有"指令"（一道白色细光）；"钱"是位置锁死的金色账户柱，
只能原地升降。** 指令走 Λ 形（A行 → 央行 → B行），每到一站那一本账涨或落 100。
开头先画一枚虚线硬币代表"钱飞过去"的错误直觉，中段推翻它。
淘汰了管道/快递分拣、轧差网收缩、水位连通器、借贷记账表格、城市俯瞰光轨。

**按判据 1 评：这不是容器。** "钱不动、账本动"正是清算的核心概念，
换成讲深海鱼完全不成立。它还自发避开了"钱是个东西在移动"这个误解
（把它降格成要被推翻的开场钩子）。
**按判据 4 评：淘汰过程同样自发留痕，理由具体到"讲的是另一个概念，适合第二集"。**

两个对照组都很强。**这是对我主张的不利证据，在看到 A1/B1 之前就记下。**

### B1 · 带 skill · 银行间清算

选定「**钱记在谁名下，就是账本上某一行字里的那个数字。钱本身从不移动，移动的只有镜头。**」
整片一镜到底：你在 A 行账上那一行减 100 → 镜头后退，A 行整本账缩成央行账上的一行 →
在这一层 A 行减、B 行加同一帧发生 → 镜头推进 B 行，收款人那一行加 100。
唯一承重的颜色是蓝墨水，只标"此刻正在被改写"的那一行。

逐条对判据：

1. **容器检查：不是容器。** "存款就是一行记录，结清就是改两行字"只对账本制的清算成立。
2. **互异性：** 映射到「**文字**」类（数字被划掉改写）+「**视角**」类（镜头的嵌套穿越）。
   待 A1 回来后比。
3. **相对 B0 的增量：有，而且方向具体。**
   B0 让"指令"作为一道白光从 A 行走到央行再到 B 行——**仍然有东西在跑**，
   只是把跑的东西从"钱"换成了"指令"。B1 把移动整个取消，改由镜头承担穿越，
   并在 style_guide 里写死「**画面里不允许任何东西在两行之间运动**（硬币、箭头、连线、粒子都不行）」。
   B1 还点出 B0 没点出的风险：**"在途"本身就是要纠正的误解**，
   竖屏大量静音播放时观众只会带走那个在飞的东西。
4. **留痕：满足，而且候选 0 被判据杀死而不是被回避。**
   候选 0 原文是"A 行、央行、B 行三个图标，一枚金币沿箭头飞过去"，
   死于刀 1——换成菜谱、融资轮次、一个人的一天都成立 → 容器。
   淘汰了 B（水罐连通：比喻不是主题性质，且同样演出"在途"）、
   C（资产=负债的秤：三刀全过但 15 秒教不会，且三杆秤并排会退回节点图并有"脸"的风险）、
   D（多视角罗生门：换视角就要另拍一镜，其中"镜头远近决定看到哪一层账"被吸收进选定方案）、
   E（硬币飞到半路冻住碎掉：一次性变形，且当钩子也要先演 2–3 秒错误版本）、
   F（金库换名牌：准备金本身也只是余额，画金条制造新误解）。

**还能追溯到具体 skill 机制的几处**（这是"增量"真实存在的证据，不是观感）：
- 「账本天然是表格，**网格容器会从这里溜回来**」→ 主动预判了这套 skill 自己的失败模式。
- 「A 行和 B 行上下排、不左右并排，避开**'脸'的形似风险**」→ 用了 `film-storyboard` 的形似风险清单。
- 「央行那一层要拿全片最长的停留，下限 2.5 秒」→ 用了**叙事权重 ≠ 物理时长**。
- `facts.md` 跑过 `factcheck.mjs`，0 错误 0 警告；主来源是英格兰银行季刊原文，
  中文旁证（汇丰转发的央行材料）**自己标了二手**；省略清单（手续费、时效、轧差、
  排队、间接参与者）记进 C01。


### A1 · 带 skill · 深海鱼

选定「**阳光就是画面里唯一的颜料**」：没有一种颜色是直接涂上去的，
每个像素 = 物体反射率 × 此刻照到的阳光 + 自发光。下潜就是把阳光一层层剥掉
（红→橙→黄→绿→蓝，顺序有 NOAA 原文出处）。红鱼**原地隐形**——不动、不淡出，
只是没有红光可反射。一千米以下只剩生物自己的光，鮟鱇的灯只照出最近的几颗牙尖。
固定镜头到底，**不出现深度标尺、不出现深度数字**，深度只靠光变表达。

- 候选 0：「深度就是一根竖向标尺，每到一层侧面弹出一张怪鱼卡片 + 标签」
  → 死于刀 1（换成"一个人的一天""融资轮次"照样能套），
  且选它的理由"竖屏放得下、分层清楚"全是画面上的好处、与主题无关。
- B（海洋雪越稀嘴越大）：三刀全过，**输在取舍**——演不了体色和发光，
  且"海洋雪"要先花 2–3 秒教。
- C（压强把鱼挤成怪形）：**事实上站不住**，登记为 `N01 否决`。
- D（我们的灯照亮多少）：二值，并进 A 当收尾，不承重。
- E（两顿饭间隔越来越长）：15 秒放不下三段递增停顿。

实跑 `factcheck.mjs`：0 错误 1 警告（F08"大嘴因食物少"只有 National Geographic 一个来源，
它自己标了单源）。
