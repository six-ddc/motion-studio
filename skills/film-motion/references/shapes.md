# 矢量形状动画：弧长采样、描边生长、变形、沿路径运动

目录：0 数据形状与 seek 下的分工 · 1 路径解析与弧长采样 · 2 描边生长 trim · 3 形状变形 morph · 4 沿路径运动 · 5 实测数字 · 6 已知局限 · 7 可用的库

四件事共用一个底座：把路径压平成折线、建累计弧长表。之后描边生长、沿路径运动、变形的每一帧都是查表。数字来自一份零依赖的自实现（记录在仓库 docs/verified/film-motion.md「shapes」一节）。

## 0. 数据形状与 seek 下的分工

- 一个子路径 = `{ pts: [[x, y], …], closed }`，一个形状 = 子路径数组。d 字符串、点数组都先转成它。
- **加载期**：解析、压平、建弧长表、morph 的重采样/配对/对齐（O(N²)）。**seek 里**：二分查弧长、线性插值。
  这些在 seek 里重建不会破坏确定性（输出只取决于参数），代价是每帧重付建表时间；点数组每帧新建时尤其要注意缓存键。
- 样式（颜色、线宽、线帽）和进度曲线都不属于几何：先把缓动套在 p 上，再交给几何函数。
- 画法统一：`beginPath(); 逐子路径 moveTo/lineTo(/closePath); stroke()` 或 `fill('nonzero' | 'evenodd')`。

## 1. 路径解析与弧长采样

**解析 SVG d**：`M L H V C S Q T A Z` 的绝对/相对写法、隐式 L、`S/T` 反射上一段控制点、Z 之后不带 M 的续画（回到子路径起点）、粘连数字（`1.5.5`、`-1-2e1`）、弧标志位不带分隔符（`a50 50 0 01100 0`）。弧先按 SVG 规范 F.6 转成中心参数化。

**压平**：Bézier 按 Wang 公式定段数 `n = ceil(sqrt(deg·(deg−1)·M / (8·tol)))`（M = 控制点二阶差分的最大长度），弧按弦高 `θ_step = 2·acos(1 − tol/r)` 定段数。

**采样器**：

```
cum[0] = 0；cum[i] = cum[i−1] + |p[i] − p[i−1]|   // 跨子路径累加，子路径之间的空跳不算长度
at(s): s 夹到 [0, L]；二分找 cum[i] ≤ s < cum[i+1]；在该段线性插值
       返回 { x, y, angle = atan2(段方向) }
slice(a, b): 取 [a, b] 之间的点，两端插值补点
```

**代价**：折线近似让弧长略短，相对误差约 `tol / (3r)`（r 为曲率半径）：tol = 0.25 px 时 r=100 为 0.08%，r=50 为 0.17%（实测 0.16%）；tol = 0.01 时 r=100 的圆周误差 0.02 px。
点数随 1/√tol 增长，r=300 的圆在 0.25 下是 78 个点。和 DOM SVG `getTotalLength()` 精确对齐的场合把 tol 调小。

这个采样器（`length` + `at(s)`）也正是沿路径排字需要的接口，可以直接给 film-typography 用。

## 2. 描边生长 trim

语义同 AE Trim Paths：start、end、offset 都是弧长比例。

```
trim(P, start, end, offset):
  a = start + offset，b = end + offset
  若 |end − start| ≥ 1 → 整条（闭合的保持闭合）；start = end → 空
  闭合路径：a、b 对 1 取模，绕过起点时把尾段和首段接成一条（不留线帽缝）
  开放路径：绕回时拆成两段（首尾各一截）
  返回 slice(a·L, b·L)
```

| 想要 | 写法 | 代价 |
|---|---|---|
| 从头描出来 | `trim(P, 0, k)` | 按弧长匀速走，弯多处看起来更慢；要按"视觉时间"走，先给 k 套缓动 |
| 两端同时收 | `trim(P, k/2, 1 − k/2)` | 收到最后剩一个点，round 线帽会留一个圆点；要干净消失就让 k 走到 1 |
| 循环跑动的光段 | `trim(P, 0, 0.2, t·速度)` | 开放路径绕回时拆成两段 |
| 多个子路径一起描 | 按总长算比例 | 短子路径一闪就过、长的拖很久；改成每个子路径各按同样比例走，代价是它们速度不同 |

描边端点和"沿路径运动到 end + offset"是同一个点：笔尖上挂东西直接共用。

## 3. 形状变形 morph

flubber 那一类方法：

1. **重采样**：每对子路径按弧长等距取 N 个点。转角 > 约 15° 的原顶点按转角从大到小各吸附一个最近的采样点——不吸附，多边形的角在 p→0⁺ 时会被削掉（吸附后实测偏差 1e-7 px 量级）。
2. **统一绕向**：有向面积 `½Σ(x_i·y_{i+1} − x_{i+1}·y_i)` 符号相反就把 b 反过来。不反的代价是中间态翻折穿过自身。
3. **对齐起点**：在 N 个循环旋转里挑逐点位移平方和最小的，O(N²)，只在加载期做。不对齐的代价是形状"拧"过去。
   开放路径改为比较正向与反向；一开一闭时把闭合的那条在最佳起点剪开，代价是剪开处有一道缝。
4. **配对**（多子路径）：贪心按"质心距离² + 面积平方根之差²"配，孔洞只和孔洞配（孔洞 = 与最大子路径绕向相反的闭合子路径）。贪心不保证全局最优，复杂情况手工指定。
5. **孤儿**（子路径数不同）：没有中性的默认，两种读法完全不同，必须由片子选：
   - 就地缩到自己的质心 / 从自己的质心长出来：读作"消失 / 出现"。
   - 缩进 / 长自对面最近的已配对子路径的质心：读作"合并 / 分裂"；代价是中途和那个子路径重叠，fill 时重叠处按填充规则叠加。
6. **插值**：逐点线性插值；p ≤ 0 返回 a 原样，p ≥ 1 返回 b 原样（孤儿不会在端点留下退化的点）。

点数可取较长那条弧长每 4 px 一个点，夹在 [32, 1000]。调参时数一数中间态里不相邻段的真相交次数（O(N²)，只给调参和测试用，别放进 seek）。

**什么时候值得**：形状之间有"是同一个东西"的关系（图标变图标、数据点变形状、logo 演绎）。差异很大的形状逐点直线插值，中段会"揉"成一团；
想要"拆开再拼"时，描边出场加描边入场往往更好读。两个形状相距很远时位移被平移主导，看起来是"边飞边变"；想先飞后变就把质心平移拆出来单独缓动。

## 4. 沿路径运动

```
along(P, p, lookahead):
  s = p·L（单个闭合子路径时 p 对 1 取模，可以一直涨；否则夹到 [0, 1]）
  位置 = P.at(s)
  朝向 = lookahead > 0 ? atan2(P.at(s + L/2) − P.at(s − L/2)) : 所在段切线
         （素材画成朝上时再加 π/2）
```

- lookahead 让折线拐角处朝向不突跳（直角处给出 45°），代价是急弯里物体"切内道"。
- 按弧长匀速走，弯道不减速；要物理感就给 p 套缓动或交给 film-physics。多子路径时 p 跨子路径会瞬移。
- 循环片的周期就是 p 走 1 的时间。

## 5. 实测数字

Node 22，Apple Silicon，`hrtime` 计时（浏览器端只确认了夹具过门 1a/1b/2/4）：

| 操作 | 数字 |
|---|---|
| 建采样器（圆 r=300） | 0.031 ms，78 个点 |
| trim 一次 | 0.003–0.007 ms |
| morph 建表（圆 → 七角星），N = 64 / 256 / 1000 | 0.20 / 0.38 / 2.39 ms（对齐是 O(N²)） |
| morph 求值一次，N = 64 / 256 / 1000 | 0.0012 / 0.0020 / 0.0078 ms |
| 方 → 五角星，19 个中间态自交 | 对齐 + 统一绕向后 0；不对齐、不统一绕向对照 13，平均位移² 27351 vs 4588 |

## 6. 已知局限

自交计数取 39 个中间态（p = k/40）：

| 情形 | 中间态自交 | 说明 |
|---|---|---|
| 凸 ↔ 凸、星 ↔ 星（五角 → 八角，N=64 或 283） | 0/39 | 按弧长对齐足够 |
| 凹形（C 形）→ 圆 | 23/39 帧，每帧最多 1 处 | 开口两侧的点要穿过开口，直线插值必然穿插 |
| 细长蛇形 → 圆 | 15/39 帧，最多 2 处 | 形状差异越大越明显 |
| 8 字（本身自交）→ 圆 | 17/39 帧 | 自交路径的有向面积与绕向没有意义，统一绕向可能挑错 |

- 中间态打结时 `nonzero` 与 `evenodd` 画出来不一样，打结处出现空洞或重叠；描边则直接看到交叉线。补救依次是：手工给配对/起点偏移、拆成两段经过一个中间形状。加点数对上表无效——打结来自几何不是采样。
- 孔洞靠绕向识别，不检查包含关系：两个分开的、绕向相反的形状会被当成"外框 + 孔"。
- 没有三角剖分式（flubber 的 separate/combine）变形，也没有按特征点（角对角）配对。

## 7. 可用的库（如需）

- **flubber**：`interpolate(a, b)` 返回 `p → d 字符串`，加载期建插值器，seek 里传 p；`separate`/`combine` 做一对多。代价是输出字符串，每帧要 `new Path2D(d)`。
- **polymorph**（polymorph-js）：类似思路，输出 d 字符串。
- **svg-path-properties**：`getPointAtLength` / `getTangentAtLength`，纯 JS，Node 里也能用，适合做 §1 的采样器。
- 浏览器里也可用 `SVGPathElement.getTotalLength()` / `getPointAtLength()`，但 Node 里没有，离线检查脚本拿不到同一组数。
