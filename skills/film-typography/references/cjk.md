# 中日韩排版

canvas 2D 不做任何 CJK 排版：没有自动换行、避头尾和标点挤压，也不支持竖排。本文说明这些排版规则与运行时函数的对应关系。规则来源：W3C《中文排版需求》（clreq）、《日文排版需求》（jlreq）、JIS X 4051。

## 1. 度量事实（Chromium 156）

- 汉字与全角标点的 advance **严格等于 1em**（chromium.md B），所以中文逐字布局可以直接 `x += size`，但**拉丁文段必须用前缀测量**。`layoutCJK` 对每个字单独调用 `measureText(ch)`，拉丁字母之间的 kerning 会丢失；拉丁字母较多的行用 `splitText` 更准确。
- `Intl.Segmenter('zh', {granularity:'word'})` 可以对中文切词（`画面/必须/是/时间/的/纯/函数`），按词交错出现的节奏更接近"阅读"的感觉。

## 2. 断行与避头尾 —— `wrapCJK(ctx, text, maxWidth)`

| 规则 | 字符 | 处理 |
|---|---|---|
| 避头（不在行首） | `、，。．：；！？」』）》〉】〕］｝"'・·ー～%‰℃々` 及日文小假名 | 把前一个单元一起推到下一行 |
| 避尾（不在行尾） | `「『（《〈【〔［｛"'` | 把它推到下一行 |
| 不可分 | 连续的 `[A-Za-z0-9'’.-]` | 当作一个单元处理，例如不会把 `seek` 拆开 |
| 连续禁则 | `。」` 这类两个避头字符相邻的情况 | 循环往回推，直到断行位置合法 |

测试（`tests/fixtures/_test-typography/tests/unit.mjs`）：`一二三四五，六七` 在 5 字宽下断成 `一二三四 / 五，六七`；`一二三四五。」六` 断成 `一二三四 / 五。」六`。

**悬挂标点**（行尾标点伸出版心半个字）：`wrapCJK` 没有实现，需要时在测宽时把行尾标点按 0.5em 计算；代价是右边缘不再是硬边。`wrapCJK` 是贪心断行，不做均衡（最后一行可能只剩一个"孤字"）；要避免这种情况，就在调用方检查末行长度，必要时缩小 maxWidth 重新排版。

## 3. 标点挤压 —— `layoutCJK(ctx, text, size, { punct })`

三种习惯都是正当的选择：

| mode | 习惯 | 观感 | 代价 |
|---|---|---|---|
| `none` | 全角式：每个标点占 1em | 规整，接近传统出版物 | 连续标点（`」，`）之间空得明显 |
| `adjacent` | 相邻标点挤压（clreq） | 规整且不显空 | 实现稍复杂 |
| `half` | 全部半角 | 紧凑、现代 | 标点存在感弱，句读不够明显 |

实测 `「好」，。啊` 在 40px 下的宽度：none 240 / adjacent 180 / half 160 px。

**字形位置取决于字体的地区版本**：简体中文字体的 `，。、` 位于 em 框左下，挤掉右半边没有问题；繁体（台湾）字体的标点通常居中，挤压后会和下一个字重叠，这时用 `none`，或者换成简体字形。开括号的字形位于 em 框右半边，挤压时要左移，所以 `layoutCJK` 给它 `shift: -0.5em`。

## 4. 全角 / 半角

- 半角数字和字母（比例宽度）与全角数字（`１２３`）都是常见习惯，文案里统一即可。
- 中英文之间加不加空格由文案决定（film-story），排版只负责既不吞掉也不多加。空格宽度由拉丁字体决定（常见 0.25–0.3em，未逐一实测），通常比 DOM `text-autospace` 的约 1/8em 宽；想要更窄的间距，就不打空格，改为在布局时设置 `x += size * 0.125`。
- 破折号 `——` 和省略号 `……` 各占 2em，中间不能断行。`toUnits` 没有把它们合并成一个单元，**这是已知缺口**：长破折号恰好落在行尾时可能被拆开。

## 5. 中英混排

- 字族栈写成 `"拉丁字族", "中文字族"`：浏览器按字形回退，拉丁字符使用前者，汉字使用后者；`loadFonts` 要对**两个**字族分别传入文字。
- 两种字体的基线和 x 高不同，拉丁文会显得偏小或偏高；要调整就用 `splitText` 拆段，单独把拉丁段放大 5–10% 并下移。

## 6. 竖排、注音、着重号（canvas 都要手画，未实现、未测）

- **竖排**：逐字 `fillText`，每个字 y 增加 1em。canvas 2D 不会应用 OpenType 的 `vert` 特性，需要用 opentype.js 取竖排替换字形，或者把 `「」（）` 旋转 90° 绘制、把 `，。` 移到右上象限；拉丁段整体旋转 90° 绘制。
- **注音（ruby）**：在每个基字上方居中绘制 0.5em 大小的注音；注音比基字宽时，要么压缩注音，要么撑开基字间距（jlreq）。
- **着重号**：在每个字下方（横排）或右侧（竖排）0.15em 处画一个点。
