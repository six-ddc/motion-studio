# 音色：维度、代价、指标、目录

缺少 `speaker` 时 `tts.py` 会直接报错；选择音色的理由写进 `_注释.音色`。本页只列**能力和代价**，不提供「X 题材用 Y 音色」这类建议，那是每支片子在 `docs/style_guide.md` 里自己做的决定。流程见 SKILL.md 第二节。

## 维度与代价

选音色的目标写成「往哪一端推、付出哪个代价」。

| 维度 | 可测指标（`voices.py` / 目录） | 往一端推的代价 | 往另一端推的代价 |
|---|---|---|---|
| 音域 | 基频中位数 Hz（男声常见 80–150，女声 180–300） | **低**：手机外放会丢掉低频，和低频的配乐、音效争抢频段，pyin 也测不稳 | **高**：长片听着累，容易显得稚气 |
| 起伏 | 基频标准差（半音）、p10–p90 跨度 | **大**：讲解句里重音放错位置会更显眼，信息句显得夸张 | **小**：有机器感，长片容易催眠（「平缓、没有自然感」的反馈多出现在这一端） |
| 语速 | 字/秒（去掉首尾静音）、发音速率（再去掉句内停顿） | **快**：留给画面反应的时间少，逐字字幕闪得快 | **慢**：总时长变长，观众容易走神 |
| 停顿 | 句内停顿的次数、总长、最长一次（≥ 0.12 s 的静音） | **多或长**：节奏拖沓；有的音色在逗号处自带长停顿，再加 `gapAfter` 或 `[停顿]` 会叠加 | **少**：没有留给画面卡拍的空隙 |
| 响度起伏 | 100 ms 窗口响度的标准差 dB | **大**：合流后的限幅和闪避效果更难预测 | **小**：听感平 |
| 辨识度 | 官方特殊标签「抖音同款 / 剪映同款 / 番茄小说同款」、名称里的 IP 角色 | **高**：观众会联想到别处（短视频腔、原 IP） | **低**：没有记忆点 |
| 指令响应度 | 同一句带指令和不带指令各合成几次，比较分布 | **强**：指令写过头也会被放大 | **弱**：逐句调整节奏只能靠 `speechRate`、标点和 `[停顿]` |
| 年代感 / 人设 | 没有直接指标，只能靠官方场景和名称推断来缩小范围 | — | — |

「这把嗓子配不配这支片子」不在上面任何一个维度上，只能靠人听。

## 指标（`voices.py` 产出，全是物理量）

| 指标 | 怎么测 | 说明不了什么 |
|---|---|---|
| 基频中位数 Hz | librosa pyin，60–500 Hz，取有声帧的中位数 | 听感是沉稳还是压抑 |
| 基频跨度 / 标准差（半音） | 有声帧从 p10 到 p90 的半音数 / 相对中位数的半音标准差 | 起伏是否落在该强调的字上 |
| 语速 字/秒 | 去掉标点后的字数，除以去掉首尾静音（-35 dB）后的时长 | 节奏感 |
| 句内停顿 次数/总长 | 以 10 ms 为一帧，低于本句 p95 −30 dB 的帧，在首尾之间连续 ≥ 0.12 s 算一次停顿 | 停顿是否在恰当的位置 |
| 响度起伏 dB | 100 ms 窗口 RMS dB 的标准差（只取有声窗口） | 轻重是否落在恰当的词上 |
| 响度 dBFS / 停顿占比 | 整段 RMS / 低于峰值 -35 dB 的帧所占比例 | 合流时会做响度归一，这两项主要用来发现异常 |

换样本句、换 `speechRate`、加指令都会让指标变化，所以**要用本片的台词来测**，改了这些之后要重测。
TTS 结果有随机性：同样条件连续合成，语速的标准差约 0.15 字/秒，基频中位数的标准差约 5 Hz。两个候选的差距比这还小时，指标分不出高下。

## 目录与候选组

`references/voice-catalog.json` 收录了官方 2.0 中文音色 98 个（`*_uranus_bigtts` 90 个，`ICL_uranus_*_tob` 8 个）。每个音色带有官方场景、特殊标签、
性别（从 ID 中取得）、名称推断（只是按名称字面推断，不代表听感）、2026-10-21 用本账号单次实测的指标，以及是否已授权。测量方法与局限写在 JSON 的 `_说明` 里
（单次合成只够粗略分档；低沉男声的基频可能被 pyin 测偏）。

```bash
.venv/bin/python <film-narration>/scripts/voices.py --list-catalog [--gender 女] [--scene 有声阅读] [--sort f0_sd_st] [--md]
.venv/bin/python <film-narration>/scripts/voices.py --list-presets          # 五组候选（historical documentary product story edge-zh），只是起点
.venv/bin/python <film-narration>/scripts/voices.py --film <slug> --preset documentary --line s1
.venv/bin/python <film-narration>/scripts/voices.py --film <slug> --voices a,b,c --line s1 --instruction "<指令>" --ab
```

`--sort` 可选 `f0_med f0_sd_st cps pause_tot loud_sd_db centroid_hz`（谱质心是明亮度的粗略代理指标，和性别、基频相关）。
`edge-zh` 组是不需要 key 的兜底方案，使用 edge-tts 的中文音色。

## 授权

98 个音色在 2026-10-21 全部用 `seed-tts-2.0` 调通（见 `voice-catalog.json` 的 `authorized`）；其余约 190 个 `ICL_uranus_*_tob` 没有测过，使用前先跑一次 `voices.py --voices <id>`。
账号授权会变化；`voices.py` 中标为 ✗ 的就是当前不可用的音色（返回码 `45000000`）。
