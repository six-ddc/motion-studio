# 取帧与派生品：转场拼图、特写起点、观看宽度、新鲜度

本文说明的图**只负责取帧，不做判定**；判据写在 checks.md。

## 1. 剪辑点来源（`scripts/_cuts.mjs`，取第一个有的，来源写进图头与 meta）

| 优先级 | 来源 | 可信度 |
|---|---|---|
| 1 | `--cuts 3.2,8.0-8.4`（单个数表示硬切，`a-b` 表示窗口） | 手动给出 |
| 2 | `window.CUT_WINDOWS = TL.transitionMarks()`（film-motion `timeline()`）加上 `window.CUTS = [硬切秒…]`（render.mjs 已支持读取） | 与画面数据同源 |
| 3 | `window.MARKS` 中首尾相接（相差 ≤ 1 帧）的位置当作硬切 | **推测**：只有 MARKS 本身按镜头分段时才准确 |
| 4 | `--scan`：计算 48×48 块的亮度帧间差，阈值为 max(4%, 中位数 ×6)；多个采样点连续超过阈值算渐变窗口，单个超过算硬切，并二分查找到具体帧 | **推测** |
| — | 以上都没有时，退回到 MARKS 中点或均匀取 5 个点，并写明"转场中段没有被专门采样" | |

**实际测到的和以为测到的不一样**：来源 3 和 4 是从别的量推测出来的。`--scan` 测的是整屏亮度变化，**同底色之间的切换会漏报，快速动作和闪白会误报**
（实测：19.33s 处的快速横移被报成了硬切）。声明不合法（非有限数、越界、起止倒置、窗口重叠）时 exit 1，不会当作"没有剪辑点"继续出图。
对照夹具 `tests/fixtures/_test-cuts/`：品红色缺陷框只出现在擦除中段 1.25–1.35s，"中"格必须落在 f39。

## 2. 每个窗口取哪 5 帧（全部对齐成片帧格 k/fps；pad 默认 max(0.3s, 3 帧)）

| 位置 | 转场 [t0, t1] | 硬切 c |
|---|---|---|
| 前 / 后 | t0 − pad / t1 + pad | c ∓ pad |
| 入 / 出 | 25% / 75% | 切前最后一帧 / 切后第二帧 |
| 中（橙框） | 窗口中点（align ≠ 0.5 时 cut 不在视觉上的半路，这一点只写进标题） | 切后第一帧 |

"中"格不是"最坏的一帧"；只闪 1–2 帧的缺陷要看 contact.sh 的特写条（12 张连续帧，对准窗口中点）。

## 3. contact.sh：帧率、特写起点、观看宽度

- 帧率读取 film.json（MP4 位于 `films/<slug>/out/` 下时），与 MP4 的 `r_frame_rate` 不一致时发出警告；特写条的每一格标注 film.json 帧号与毫秒数（毫秒按 MP4 实际帧率计算）。
- 特写起点按优先级选取：手动给出的秒数，其次是 `transitions.png.meta.json` 中第 K 个窗口（`--strip-cut K`，起点为中点前 6 帧），最后是时长的 35% 处（会明确提示可能落在平台期）。
- 观看宽度：默认按**竖持手机 360** 计算（横版片在竖持的手机上占满宽度）；style_guide 的 `view_width` 优先于默认值；`--hold landscape` 让横版片按 720 计算；`--view-width N` 直接指定宽度。
  图头会写明用了哪种假设。check.mjs 的 `readability` 用的是同一个 `view_width`；只在 contact.sh 上切换宽度而不改 style_guide 时，两边判定的就是两种不同的手机。

## 4. 派生品新鲜度（`_fresh.mjs` / `fresh.mjs`）

每个产物旁边都有一份 `<产物>.meta.json`，记录片子目录中除 `out/ docs/ tools/ receipt.json` 以外每个文件的 md5（film.json 去掉 `renderer` 字段后计算）、
contact 类产物的源 MP4 大小与 mtime，以及本图的取帧表和所用假设。判定规则：全部一致为新鲜；任一项不一致为过期（报告会点名是哪个文件）；没有 meta 为未知（不当作新鲜）。
**实际测到的和以为测到的不一样**：这里测的是输入是否逐字节相同，而不是画面有没有变化（改了注释也算过期）；片子目录之外的资源变化检测不到；contact 类产物新鲜只说明它与那个 MP4 一致，
MP4 本身是否最新由 film-core 的 accept / 收据负责。review_log.mjs 会在每轮开头用 ⚠ 列出过期项；只有 `fresh.mjs --strict` 才会改变退出码；`--selftest` 运行阴性/阳性对照。
