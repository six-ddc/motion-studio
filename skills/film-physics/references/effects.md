# 各类物理效果：原理、seek 下的难点、代价与坑

目录：1 粒子与发射器 · 2 弹道与落地弹跳 · 3 弹簧、摆与轨道 · 4 刚体碰撞与约束 · 5 布料与绳索（Verlet） · 6 群集 boids · 7 流体近似

每节按 原理 → 在 seek(t) 下难在哪 → 代价 / 什么时候值得 → 坑 → 可用的库 写。公式够你自己写出来；参数怎么取是本片的事。
跟车/排队见 `chain.md`，屏震/顿帧等反馈见 `events.md`，引擎改造见 `libraries.md`。坐标用"仿真单位"，画的时候用 film-core layout 的 `size()/place()` 换算成像素，不写死。

## 1. 粒子与发射器（策略 ①）

**原理**：发射器是一个**关于生命周期的函数**，不是一个往数组里 push 的循环。

```
粒子 i 出生于 born_i = start + i/rate，寿命 life_i = life·(1 + jitter·(2·hash01(seed,i,999) − 1))
emit(t): for i in [ceil((t − maxLife − start)·rate), floor((min(t,end) − start)·rate)]:
           age = t − born_i；0 ≤ age < life_i 的才在场；属性 r(k) = hash01(seed, key_i, k)
位置 = 主运动(age)（弹道、阻力，见 §2） + 可选噪声位移(age)
```
- 爆发：count 个粒子同一时刻出生，`age = t − at`，下标就是 0..count−1。
- 循环：`key_i = i mod N`，N = rate·L 必须是整数，首帧末帧逐像素相同（`strategies.md` §2）。预热：允许负下标，片头就是稳态。
- 可变发射率 rate(t)：先求累积发射量 N(t) = ∫rate，粒子 i 出生于 N⁻¹(i)。N 有闭式就直接反解，没有就加载期二分。
- 场力：常力 + 线性阻力有闭式解（§2）；指向一点的引力、湍流、涡流没有。

**难在哪**：下标区间两端的 floor/ceil 要带 1e-9 级的容差，否则 t 恰好落在出生时刻时会在顺序/乱序之间差一个粒子。"雪花在风里打转、被涡流卷走"这类需要积分速度场的轨迹没有闭式。

**代价**：O(rate × life)，与片长无关。实测 2000 粒子 0.5 ms/帧、20000 粒子 4.4 ms/帧（CPU 求位置；画的代价另算）。
真要平流（粒子沿 curl 场走）只能 ②，代价是粒子数 × 步数；粒子多又要平流时考虑 ③。

**坑**：
- 用 `seeded()` 顺序抽属性：seek 到 t 要先抽掉前面所有粒子的数，O(总发射数)，且一旦乱序就错。
- 噪声位移只摆不漂：做出来是"原地晃"，不是"被风吹走"。需要漂移就把漂移项写成 age 的闭式（如 `drift·age`）叠上去。
- 着色器里算粒子位置（float32）与 JS（double）不能逐位一致；锚点、碰撞要以 JS 算的为准。

**库**：通常不需要。GPU 闭式粒子（位置在顶点着色器里由 age 算）见 film-webfx。

## 2. 弹道与落地弹跳（策略 ①）

**弹道**（逐轴独立，v' = g − k·v）：
```
k = 0：x(t) = x0 + v0·t + ½g·t²
k > 0：x(t) = x0 + (g/k)·t + (v0 − g/k)·(1 − e^{−kt})/k，   v(t) = g/k + (v0 − g/k)·e^{−kt}
```
二次阻力（v' = g − k|v|v）没有二维初等闭式解；一维竖直下落有（tanh 形），斜抛要走 ②。

**平面弹跳**（画布坐标 y 向下，地面 floor，恢复系数 e∈[0,1)）：
```
首次触地 t1：解 y0 + v0·τ + ½g·τ² = floor 的正根
反弹初速 u = e·(v0 + g·t1)；第 n 段飞行时长 2u·eⁿ/g，构成等比数列
s = t − t1；静止时刻 tRest = 2u/(g(1−e))；s ≥ tRest 就停在地上
否则 n = floor( log(1 − s·g(1−e)/(2u)) / log e )，S_n = (2u/g)(1−eⁿ)/(1−e)，τ = s − S_n
y = floor − (u·eⁿ·τ − ½g·τ²)；最近触地 lastHit = t1 + S_n；触地速度 = u·eⁿ/e
```
**难在哪**：e<1 时跳次数无穷但总时长有限（Zeno 点），逐跳累加会死循环或在 tRest 附近数值抖动，必须先判 tRest。`lastHit`、触地速度是派生事件，屏震、压扁、音效 cue 都从它推，仍是纯函数。

**代价**：O(1)。值得在任何"一个物体落地弹几下"的场合用；斜面、多面墙反射、体间相撞都超出它，走 ②。

**坑**：u 极小时 log 的参数趋近 1，n 的计算会不稳——u < 1e-9 直接判静止。水平方向的摩擦（每次触地 vx·0.98）也能闭式写成 vx·μⁿ，但要和 n 共用同一个计算结果。

## 3. 弹簧、摆与轨道（策略 ①）

**弹簧**：x'' + c·x' + k·(x − target) = 0 是二阶线性 ODE，按判别式 c² − 4k 分欠阻尼/临界/过阻尼三支闭式。film-core 已有：`motion.js` 的 `settle()`（从 0 到 1）和 `events.js` 的 `oscillate(t, x0, v0, target, k, c)`（任意初速度，同时给速度）。不必重写。

**单摆**：小角度线性化后就是 k = g/L 的弹簧。**摆角超过约 30° 时周期误差 > 2%**。大角度要么接受误差，要么走 ②（定步积分 θ'' = −(g/L)·sin θ，单摆很便宜），要么用完全椭圆积分算精确周期再套周期函数（只解决周期，不解决波形）。

**开普勒轨道**（二体）：
```
M = 2π·t/period + phase；解 M = E − e·sin E（牛顿迭代，E₀ = M（e<0.8）或 π，固定 8 次）
x = a(cos E − e)，y = a·√(1−e²)·sin E，再旋转 rot
```
**难在哪**：高偏心率（e→1）时牛顿法从 M 起步可能不收敛，所以 e≥0.8 从 π 起步；固定迭代次数保证每个 t 走同样多步。多体（三体、行星互扰）没有闭式解，走 ②，且是混沌的：子步数、积分器一变，长时间后的结果就完全不同——定稿后不要改。

**代价**：O(1)。多体用辛积分器（速度 Verlet / leapfrog）走 ② 能量更守恒，代价与显式欧拉相同。

## 4. 刚体碰撞与约束（策略 ② / ③）

**原理**（最小可用的圆形刚体，自己写就够）：
```
每子步：v += g·dt；x += v·dt（半隐式欧拉）
  墙/地：穿透就推回并 v_n = −e·v_n
  宽相：均匀网格（格宽 = 最大直径），每步开头重建
  窄相：对 3×3 邻域内 j > i 的对：d < r_i + r_j 时
        位置修正：各推开 (rr − d)/2 沿法线
        冲量：rv = (v_j − v_i)·n；rv < 0 时 j = −(1+e)·rv/2，v_i −= j·n，v_j += j·n（等质量）
  强碰撞（|v_n| > 阈值）记一个事件进 state 的环形缓冲
```
分批出生：出生步号在加载期由 `hash01` 定好，`step` 里按 `k >= born[i]` 判断活着，不在 state 里维护"已出生"计数也行。

**难在哪**：全局耦合，没有闭式；结果依赖遍历顺序（Gauss–Seidel 式逐对修正），所以对的枚举顺序必须由数组下标决定，不能依赖 Map/Set 的插入顺序或网格里的链表顺序变化。子步数直接决定结果。

**代价**：参考实现每步 0.034 / 0.087 / 0.42 ms（n≈300 / 1000 / 3000，Node）。300 球 10 s 冷启动约 80 ms；乱序最坏 = 1 仿真秒的步数。片子长、球多、要多机并行渲染时转 ③。
需要多边形、关节、摩擦、堆叠稳定性时自己写不划算，用引擎（`libraries.md`）。

**坑**：
- 只修位置不加冲量会"粘"在一起；只加冲量不修位置会互相穿过去慢慢分开。两者都要。
- e 太接近 1 加上位置修正会注入能量，堆叠时会抖。
- 碰撞事件存在闭包数组里：回退后事件表不回退，屏震会在没撞的帧上出现。

**库**：matter.js、planck.js、rapier（`libraries.md`）。

## 5. 布料与绳索：Verlet（策略 ② / ③）

**原理**：位置式积分，速度藏在上一帧位置里。
```
每子步：
  对每个未钉住的点：vel = (x − px)·damping；px = x；x += vel + a·dt²（a = 重力 + 风）
  重复 iters 次：对每条约束 (a,b, 静长 L)：d = |x_b − x_a|，diff = (d − L)/d
                  按权重各移一半（一端钉住时另一端移全部）
```
网格的横、竖相邻点连约束就是布；只有一列就是绳。加对角约束抗剪切，隔一个点连约束抗弯曲。
风：每 0.25 s 换一个强度，强度取 `hash01(seed, floor(t·4), 0)`，t = 步号 × dt；每个点再乘一个自己的 `hash01(seed, i, 1)` 让布面不整齐。

**难在哪**：state 要包括 x 和 px 两份位置，clone 漏掉 px 就等于每次恢复检查点时速度清零。约束迭代是 Gauss–Seidel，顺序固定在约束数组里。

**代价**：参考实现每步 0.064 / 0.15 / 0.41 ms（n≈300 / 1000 / 3000 点，Node）。iters 越多越"不伸长"，每步代价线性增加。

**坑**：iters 和 substeps 一起决定布的软硬，二者都会改变结果；"布太软像橡皮"多半是 iters 不够，而不是刚度参数。撕裂（约束超长就删除）是一次性开关，被删的约束列表必须在 state 里。

**库**：一般不需要。要和刚体互动（布挂在会动的物体上）时，rapier 的关节可以做绳，但布的观感不如 Verlet 好调。

## 6. 群集 boids（策略 ② / ③）

**原理**（Reynolds 1987）：每个体只看视距 view 内的邻居。
```
分离：对 d < sep 的邻居，s −= (dx/d)·(sep − d)
对齐：avgV − v_i
聚合：avg(dx) （邻居相对位置的均值）
a_i = wSep·s + wAli·对齐 + wCoh·聚合
先对所有 i 算完 a_i，再统一 v += a·dt，限速到 [vMin, vMax]，x += v·dt，边界取模（环面）或转向
```
**难在哪**：必须"先全部算加速度再统一更新"（Jacobi 式）。边算边改会让下标小的体先动，结果依赖顺序——这本身仍是确定的，但改个体数就会让整群形态大变，调参无法收敛。邻居查询用每步重建的网格（草稿缓冲）。

**代价**：参考实现每步 0.081 / 0.34 / 2.2 ms（n≈300 / 1000 / 3000，Node）；3000 体时 ② 乱序最坏要重放 1 秒 ≈ 130 ms 以上，建议 ③。

**坑**：不设最低速度，群会停成一团；只设最高速度，转向会显得僵。环面边界下"跨边"的邻居要按最短距离算，否则边缘处的群会被撕开。

**库**：不需要。

## 7. 流体近似：Clavet 双密度松弛（策略 ③ 为主）

**原理**（Clavet 等 2005，粒子流体，不是网格 Navier–Stokes）：
```
每步：v += g·dt；px = x；x += v·dt                        （预测）
  对每个 i：q_j = 1 − |x_j − x_i|/h（q>0 的邻居）
            ρ = Σq²，ρ_near = Σq³
            P = k·(ρ − ρ0)，P_near = k_near·ρ_near
            对每个邻居：D = dt²·(P·q + P_near·q²)·n̂；x_j += D/2，x_i −= D/2
            粘性：邻居速度差 × visc × q，双方各分一半
  边界：夹到容器内
  v = (x − px)/dt                                            （由位置反推速度）
```
**难在哪**：每步最贵（每对邻居要访问两遍），而且是"边算边改"的位置松弛，遍历顺序固定在下标上。不可压缩性只靠松弛，粒子数和 dt 一起决定观感；改任何一个都要重看整段。

**代价**：参考实现每步 0.89 / 3.4 / 13.1 ms（n≈300 / 1000 / 3000，Node）。**超过 1000 粒子时 ② 的乱序 seek 到秒级，基本只能 ③**。

**什么时候值得**：要"一盆水晃动、一摊浆流下来"的整体观感，且水与物体有互动时。只要烟、雾、墨这类视觉流动，网格流体或程序化噪声在着色器里做更便宜，归 film-webfx（帧间反馈要可 seek，见那边的做法）。

**坑**：粒子画成点看起来像沙子；液面通常要再做一次屏幕空间处理（模糊 + 阈值、metaball），那一步归 film-webfx。

**库**：没有维护良好的 JS 实现可直接拿来；LiquidFun（Box2D 的流体分支）有 wasm 移植，**本仓库没有试过**。

估算乱序最坏：`ms/步 × fps × substeps × 检查点间隔（仿真秒）`。各节的每步耗时是 Node 单进程参考实现；浏览器内的实测见仓库 docs/verified/film-physics.md §3。
