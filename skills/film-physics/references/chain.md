# 一维跟随链：跟车、幽灵堵车、红绿灯起步、排队

目录：1 什么时候该用 · 2 模型 · 3 两个无量纲数 · 4 实测区间表 · 5 按物理量反解形状参数 · 6 设计流程 · 7 排队 / 直路 · 8 在 seek 下的坑 · 9 代价

本页的数字来自仓库内对 OVM + 安全项参考实现的扫参（来历见仓库 docs/verified/film-physics.md §6）。模型自己写，几十行；难的是参数设计，本页主要讲这个。

## 1. 什么时候该用

一串单元排成一列，**每个单元只看前面那一个**，按间距调整自己的速度。刹车、起步、拥挤这类信号会**逆着运动方向**往后传，传递过程中被放大或衰减。

| 现象 | 用什么 | 为什么 |
|---|---|---|
| 幽灵堵车、走走停停、红绿灯起步波、队伍一截一截往前挪、车厢松紧波 | 跟随链（策略 ②） | 波速和振幅是**涌现**的，取决于参数，必须算出来 |
| 多米诺式逐个点亮、人浪、接力、固定延迟的传递 | **闭式**：第 i 个在 `t0 + i·δ` 触发 | 延迟是常数时没有动力学，写仿真只是白付 O(t) |
| 二维人群、绕行、超车换道 | boids 或自己写（`effects.md` §6） | 一维链假设先后顺序永不变 |
| 单元之间碰撞反弹 | 刚体（`effects.md` §4）或引擎 | 链里的安全项是防碰撞，不是碰后反弹 |

## 2. 模型

最优速度模型（OVM，Bando 等 1995）：

```
dv_i/dt = a·( V(h_i) − v_i )          h_i = x_{i+1} − x_i（车头到车头；环上取模）
V(h) = max(0, V0(h) − V0(hs))，V0(h) = (vmax/2)·(1 + tanh((h − hc)/w))，hs = unitLen + stopGap
```
可选的**运动学安全项**：当 v_i > v_{i+1}（正在逼近）时，加速度至少取"恰好在前者速度上停住"所需的减速度
`−(v_i² − v_{i+1}²) / (2·max(minDen, 净距 − safeGap))`；可以加一个介入阈值 safeOnset，所需减速度超过它才介入。

| 量 | 物理含义 | 单位 |
|---|---|---|
| h0（环上 = L/n） | 平衡车头间距（密度的倒数） | 长度 |
| hs = unitLen + stopGap | 停住时的车头间距 | 长度 |
| V(h) | 间距为 h 时想开多快；vCruise = V(h0)，vFree = V(∞) | 速度 |
| a | 敏感度 = 1/松弛时间 | 1/s |
| V'(h0) | 平衡点上间距每增 1，期望速度增多少 | 1/s |
| 扰动 | 从仿真时刻 t 起持续 dur 秒，某单元至少以 decel 减速 | — |
| 虚拟前车 leader(tSim) | 直路最前一个单元跟随的对象，`{x, v}` 或 null（前方空，按 V(∞)） | — |
| 噪声 | 每步每单元加 `noise·(2·hash01(seed, 步号, i) − 1)` | 加速度 |

积分用半隐式欧拉：先对所有 i 算加速度（草稿缓冲），再统一 `v = max(0, v + acc·dt)`、`x += v·dt`；dt = 1/240 是本页数字的条件。

**单位**：模型对长度和速度的整体缩放严格不变（米制和 ×100 像素制的成堵时间在 0.1 s 内相同），但 safeGap、minDen、stopV（判"停住"的速度阈值）本身是长度/速度，换单位时要一起换。

## 3. 两个无量纲数：一个管"堵不堵"，一个管"撞不撞"

```
κ  = 2·V'(h0) / a             失稳裕度
A* = a·(h0 − hs) / V(h0)      余量比 = 富余净距 / 一个松弛时间里开过的距离
```

**会不会堵由 κ 决定，线性理论给的是精确结论**：κ > 1 时均匀流失稳。增长率 growth 是特征方程 `σ² + aσ = aV'·(e^{iθ} − 1)` 在所有模态上最大的实部（环上 θ_k = 2πk/n，k = 1..n−1；直路 θ ∈ (0, π]），解是 `σ = (−a + √(a² + 4aV'(cosθ − 1 + i·sinθ)))/2`。efold = 1/growth 是扰动放大到 e 倍的时间。实测（关闭安全项）：
- κ < 1：扰动全部衰减，180 s 内从未成堵。
- κ 刚过 1：理论失稳，但 efold 长达几百秒（κ=1.1 时 211–422 s），片子时长里等于不堵。
- 成堵时间（速度极差达到 V(h0) 的一半）约 **0.7–2 倍 efold**。
- 长波线性波速 `c = V(h0) − h0·V'(h0)`（负 = 逆行），但成堵后堵团的速度是非线性的，与它相差 2–3 倍，要实测。

**会不会撞由 A\* 决定，边界来自实测**：纯 OVM 失稳后，**A* ≤ 1.15 全部相撞**（穿过前车），**A* ≥ 1.38 全部不撞**，中间没有样本（40 组：4 种几何加像素单位，κ = 2/3）。直观理解：一个松弛时间里开过的距离比富余净距还长，就来不及反应。

**安全项的代价**：开启后永不相撞（下表最小净距 ≥ 1.15 m），但它本质上是速度差阻尼，**会把失稳门槛往上推**：a=1 时要 κ ≈ 4 才堵，a=2 时 κ=1.6 已经不堵。线性理论只对关闭安全项成立；"κ > 1 却不堵"多半是安全项开着。

## 5. 按物理量反解形状参数

hc、w 没有直接的物理含义，手扫的代价是几十组试错。改为给定 h0、hs、vCruise、vFree、a、κ，反解 vmax、hc、w：
```
三个约束：V(∞) = vFree，V(h0) = vCruise，V'(h0) = κ·a/2
令 u0 = (h0 − hc)/w，ρ = vCruise/vFree，D = h0 − hs：
  T0 = tanh u0，Ts = (T0 − ρ)/(1 − ρ)，us = atanh Ts
  w = D/(u0 − us)，vmax = 2·vFree/(1 − Ts)，hc = h0 − u0·w
  V'(h0) = (vmax/(2w))·(1 − T0²) 随 u0 单调下降 → 在 (atanh(2ρ−1), atanh(2ρ−1)+3) 上二分
```
可达的最缓斜率在区间上端；要求的 V'(h0) 比它还缓就**不可行**，要明确报出来（"κ 至少要 X"），并提示该调哪个量：加大 a、拉开 h0−hs、让 vCruise 更接近 vFree。上表那组几何在 a=1 时 κ 下限是 1.25（斜率不能低于 0.625/s）。

## 6. 设计流程

1. **定几何和速度**：h0（或 L、n）、unitLen、stopGap、vCruise、vFree。来自 facts.md，不是调参得到。
2. **定 a，算 A\***：A* ≥ 1.4 可以关安全项，线性理论的预测就是准的；A* < 1.4 必须开安全项，κ 按 §4 选。
3. **定 κ**：按"片子允许多久后成堵"选。关安全项时成堵 ≈ 0.7–2 × efold；开安全项时查表。用 §5 反解形状参数。
4. **无头试跑**：在 Node 或场景的 `ready` 里从 init 跑 T 秒，统计 撞没撞 / 最小净距 / 首次成堵 / 首次停住 / 堵团速度（堵 = 速度极差 > 0.5·V(h0)；堵团中心 = 速度 < 0.5·V(h0) 的单元中心，环上用圆周平均）。22 单元跑 180 s 约 50 ms。不满足就回第 2 或 3 步只改一个量，不去动 hc/w。
5. **把事件对齐到旁白**：用 `timemap.js` 的 `fitRate` 让"首次停住"落在旁白锚点上（`timemap.md` §5）。
6. **声明断言**：在 `window.PHYS.claims` 里写"不撞""锚点前没停""锚点后停过"，由 physcheck F 组对着真实画面验（`timemap.md` §6）。

## 7. 排队 / 直路

- 直路：x 不取模，0 号在最后，n−1 号在最前；最前一个跟随 leader(tSim)（**必须是仿真时间的纯函数**）。
- 排队起步：单元首尾相接、静止（间距 hs），一开始全部标为"停着"。
- 红灯：停止线在 X 时，`leader = (t) => t < tGreen ? { x: X + unitLen, v: 0 } : null`。§4 那组几何、a=1、κ≈4、开安全项时 12 辆车排队，绿灯后每辆比前一辆晚 **1.15 s** 起步（第一辆晚 0.97 s），起步波约 13.5 km/h 往后传，最小净距 0.50 m（= stopGap）。
- 直路均匀流扰动：κ=4、a=2 时 40 辆车里扰动越往后越大（各处最低速从前往后 5.95、4.27、1.55、0.49、0.25 m/s，约从第 20 辆起被逼停）；κ=1.5 时不放大（从第 5 辆起最低速稳定在 7.1–7.5 m/s）。

## 8. 在 seek 下的坑

- **扰动是否已施加**：按步号判断 `k·dt ∈ [t, t+dur)`，不用闭包里的 `fired` 标志（回退时不复位，见 `strategies.md` §3）。
- **统计量也是状态**：最小净距、首次停住时刻、每个单元是否停过、步号本身，都要放在 state 里随检查点回退。
- 环上取模：只在越界时 `x −= L`；每步都写 `(x + L) % L` 会引入舍入，乱序结果仍一致但与连续积分不同。
- 扰动时刻、leader 的时刻都用**仿真秒**；旁白锚点是影片秒，要过 `S(·)`（`timemap.md` §3）。

## 9. 代价

| | 数字（Node，dt=1/240，检查点间隔 1 s） |
|---|---|
| 每步耗时 | n=300 时 0.031 ms；1000 时 0.052 ms；3000 时 0.154 ms |
| 检查点 | 每个约 n × 33 B（300 单元约 9.7 KiB，3000 约 96.7 KiB） |
| 乱序最坏 seek | 走 1 仿真秒：n=300 时 7.5 ms，3000 时 37 ms |
| 浏览器（physcheck，22 单元加绘制，8 s 片子压进 31.8 仿真秒） | 顺序 0.15 ms/帧，乱序平均 1.19 ms、最大 5.6 ms，冷启动 seek(8) 10.3 ms |

时间加速 W 倍时，顺序渲染每帧走 W 倍步数，冷启动走 S(t) 对应的步数，见 `timemap.md` §4。
