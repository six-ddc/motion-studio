# 风格词汇表：转场 · 节奏 · 构图

目录：1. 转场 · 2. 节奏 · 3. 构图（含形似风险速查）

这是菜单，不是规则：每条写明"适合什么、代价是什么"。本片用了哪些、拒绝了哪些，写进 `docs/style_guide.md` 并指回机制。先弄清机制需要什么再来这里找；反过来从这里挑（"我想用个推页"），会把片子拉回手法拼盘。

## 1. 转场

| 手法 | 适合 | 代价 |
|---|---|---|
| **机制延续**（不转场：上一镜的结束状态就是下一镜的初始状态） | 机制驱动的片子的默认选项；状态变量连续变化时 | 需要整片处在一个连续空间里，实现时要提前规划所有元素的生命周期；做不出"翻篇"的感觉 |
| **共享元素交棒**（A 里的某个物件变成 B 里的某个物件） | 两个场景有语义关联，希望观众感受到因果 | 每次都要设计一个说得通的变形；用多了像炫技，观众会开始猜下一个会变成什么 |
| **形状匹配剪**（match cut，把形状相似的两个东西硬接） | 揭示两个东西隐含的相似 | 只有形似真正有意义时才有力；为了接而接会显得刻意 |
| **硬切** | 主题本身有断裂（战争、崩溃、密钥翻转）；节拍点 | 会断开空间连续性，用在不该断的地方像剪错了。用在主题断点上则最有力，因为剪辑断点和主题断点重合 |
| **机制擦除**（用机制本身的材料擦过画面：墨漫过去、文字乱码化扫过） | 状态切换时，想留在机制本身的语汇里 | 擦除的方向和速度会被观众读出含义；需要时间（盖过最远的角通常要 0.3s 以上，否则像闪了一下） |
| **尺度穿越**（推进到一个细节里面，细节变成新的世界） | 层级结构（从宏观到微观、从组织到个人） | 相机运动幅度大，容易晕；穿越点要有足够的细节撑住放大 |
| **叠化** | 时间流逝、记忆、两个状态共存的那一刻 | 软，没有记忆点；两层叠加时中间帧容易显脏。廉价，但不算错 |
| **淡入淡出（经黑/白）** | 章节分隔、开场与收场、给观众喘口气 | 会打断能量，观众会以为"结束了"。整片只用它会像幻灯片 |
| **推页 / 滑入** | UI 产品片、模拟真实界面行为 | 带有强烈的界面语汇，放在叙事片里像 PPT |

## 2. 节奏

| 模式 | 适合 | 代价 |
|---|---|---|
| **句锁**（事件对齐到旁白里的词，`s3@裂痕`） | 由旁白承载信息的片子；默认的对齐方式 | 节奏完全由 TTS 语速决定，没有音乐性；词密集的句子会把事件挤在一起 |
| **拍锁**（事件对齐到音乐节拍栅格，参见 film-narration 的 beats） | 有配乐、偏情绪或宣传的片子 | 可能和旁白的词冲突；需要决定谁让谁 |
| **叙事权重分配**（重要区间独占一句旁白，次要区间压缩） | 自变量有物理单位的主题（年份、字节、金额） | 时间轴不再"诚实"，观众可能误读比例；必要时加刻度提示真实比例 |
| **加速（渐密）** | 失控、堆积、加速衰败 | 后段信息密度高，在 360px 下可能读不清 |
| **减速（渐疏）** | 收束、沉淀、余韵 | 观众可能在末段走神；需要一个值得看的东西撑住 |
| **静止留白** | 重要时刻之后让这一刻沉淀下来；和前面的密度形成对比 | 超过一定时长会被读成"卡住了"或"没东西了"。值不值得，取决于画面里还有没有在缓慢变化的东西（一圈仍在洇开的墨边可以撑很久，一张静止的卡片撑不过一秒） |
| **错峰级联**（一组元素以 0.05s 间隔依次入场） | 列表、批量出现的同类物 | 能便宜地制造出"很多变化"，是网格片的标志性动作；会被看成 UI 模板 |
| **呼应**（旁白说一句，画面回应一下；或者反过来） | 解说片、教学片 | 规律太强会让人昏昏欲睡；需要偶尔打破 |
| **固定变化密度**（每 N 秒必有新事件） | 短视频平台、注意力竞争激烈的场景 | 会奖励廉价的变化（多弹几个格子就达标）；和"静止留白"天然冲突，取舍写进 style_guide |

## 3. 构图

| 策略 | 适合 | 代价 |
|---|---|---|
| **单主体居中** | 机制集中在一个物件上（一团墨、一张纸） | 对称、稳定，但容易显得呆板；配上渐变背景和大标题，就是"默认片"的长相 |
| **偏心 + 负空间** | 需要呼吸感，要给文字或后续元素留位置 | 在竖屏（9:16）上负空间容易显得空；负空间本身需要有质感 |
| **减法构图**（主体由挖空或缺失构成，比如宫阙从墨里挖出） | 主题是"失去""剩下""显影" | 读图需要一点时间；挖出的形状要有足够的辨识度 |
| **满幅材质**（整个画面就是材料本身：纸、水、屏幕噪声） | 机制是物质类变量 | 没有明确的焦点，需要别的手段引导视线 |
| **尺度对比**（极大和极小并置） | 数量级差异、个体与整体 | 小的那一端在 360px 宽度下可能看不见 |
| **三元/对称排列** | 庄重、仪式感、三方关系 | **形似风险：品字或倒品字会被看成人脸**（唐片的三座殿宇）。想要脸时这反而是优点 |
| **放射排列** | 中心辐射、扩散 | 形似风险：会被看成太阳、病毒、爆炸、齿轮 |
| **阵列 / 网格** | 内容本身就是同质的集合（像素、坊市、批量数据），并且网格不承重 | 什么主题都能装，所以它不会让这支片子和别的片子有所不同；最好写，也最容易成为默认 |
| **分屏** | 对比两个状态、呈现双方视角 | 容器性质强；两半在 360px 下都要能各自读清 |
| **画中画 / 边框** | 屏幕里的屏幕、档案、引用 | 增加一层"被展示"的距离感；边框在小屏上占地方 |
| **四角标签** | 数据片、仪表盘、技术感 | 带有 HUD/UI 语汇；在叙事片里像水印 |
| **文字即物体**（文字本身受机制作用：被墨吞没、被加密） | 文字和机制同构的片子 | 可读性随机制变化，重要信息要另找通道传达（比如旁白） |
| **文字即字幕**（文字在画面之外的另一层） | 需要稳定可读 | 和画面是两层，同构感弱 |

### 形似风险速查（写关键帧剪影描述时对一遍）

两点一横线加下方的横向形状，会被看成脸；等间隔的独立尖刺轮廓，会被看成齿轮、星形、爆炸贴纸；圆加放射线，会被看成太阳、病毒；竖长物顶上一个圆，会被看成人；两圆部分相叠，会被看成维恩图（读成"交集"）；大圆里有很多小圆，会被看成细胞、气泡。这不是禁止清单：写下来，是为了让"像什么"成为一个有意做出的**决定**，而不是意外。
