# 传播力、KOL 脚本设计与听觉文案参考

目录：[1. 前 3 秒停留机制与静音首帧](#1-前-3-秒停留机制与静音首帧) · [2. 中段完播与注意力滑梯](#2-中段完播与注意力滑梯) · [3. 给耳朵写的口播：人设、密度与音画关系](#3-给耳朵写的口播人设密度与音画关系) · [4. 社交传播驱动力与营销转化弧线](#4-社交传播驱动力与营销转化弧线) · [5. 平台语境与画幅心理](#5-平台语境与画幅心理)

这份文件提供**像成熟视频博主（KOL）一样设计脚本与画面钩子**的方法论参考。它不是固定模板——不同题材、受众和渠道需要的开场、节奏和转化力度截然不同；下面每一种手法都同时列出**适用场景**与**代价/副作用**，按本片目标取舍。

## 1. 前 3 秒停留机制与静音首帧

在信息流里，观众的默认动作是划走。前 3 秒的任务不是"把背景交代完整"，而是给观众一个**不划走的理由**（认知缺口、利益相关或感官反差）。百科式开场（"XX 诞生于某年，是一种……"）零风险，但代价是熟人觉得老套、路人觉得与己无关。

| 钩子原型 | 做法 | 适合什么题 | 代价与翻车点 |
|---|---|---|---|
| **反常识 / 破误区** | 直接亮出与受众默认认知相反的结论（"真正拖慢系统的不是慢查询，而是……"） | 科普、技术拆解、行业洞察 | 后文证据如果撑不住开场的反差，会被观众判为标题党、损耗信任 |
| **痛点嘴替 / 具体摩擦** | 一句话戳中受众刚经历过的具体狼狈时刻，替他说出痛处 | 产品种草、效率工具、职场方法 | 圈层精准度高，但痛点之外的泛人群会直接划走 |
| **终局前置（倒叙）** | 第 0 秒直接给最反常的结果画面或崩溃瞬间，再追问"怎么走到这一步的" | 历史兴衰、事故复盘、仿真实验 | 终局画面在片尾往往要再呼应一次，篇幅极短（<15s）时略显重复 |
| **极端量级对比** | 把抽象规模压成两个悬殊且具象的数（如"125 万发行额，本钱只有 36 万"） | 数据故事、商业案例、财经 | 数字必须经得起 `facts.md` 核查；堆砌三个以上数字反而让耳朵失焦 |
| **预测 / 赌约互动** | 摆出两个选项或实验初始态，让观众先在心里押注哪边赢 | 物理仿真、博弈规则、A/B 实测 | 铺垫规则若超过 4 秒仍未开跑，好奇心会提前耗尽 |
| **静音视觉奇观** | 第 0 帧直接处于动态张力中（非静态标题卡），靠画面自身的异常留人 | 视觉先行片、设计展示、实物/3D 演绎 | 首帧构图本身必须自解释；若只是一团看不懂的粒子，停留不会转成完播 |

**0 秒静音首帧测试**：主流社媒信息流常默认静音起播。关掉声音只看前 2 秒画面与核心大字，检查观众能否一眼看懂"什么东西正在发生异常或冲突"（实现后可配合 `film-critique` 的 `hook`、`mute` 检查项复核）。

## 2. 中段完播与注意力滑梯

很多片子赢了前 3 秒，却在第 8 秒断崖掉人——常见原因是钩子抛完后立刻退回"第一、第二、第三"的平铺罗列，或者第 5 秒就把底牌全交了。

| 留存机制 | 怎么运作 | 代价与适用边界 |
|---|---|---|
| **未闭合悬念环（Open Loop）** | 解开眼前的局部问题时，顺手揭示一个更深层的隐患（"表面看修好了，但真正的雷才刚开始跳"） | 适合 45s 以上的叙事或拆解；环开得太多却不及时闭合，观众会产生被吊胃口的疲惫感 |
| **认知滑梯（逐层加码）** | 不横向并列三个平行点，而是顺着一条因果链每 10–15 秒推翻一层浅解释、逼近本质 | 论证密度高、爽感强；代价是观众中途漏听一句就容易掉队，关键转折处需要画面给足视觉锚点 |
| **中段再钩（节奏换挡）** | 在中段注意力松懈区，用一次景别跳切、半秒刻意静音（`[停顿 0.5]`）或视角切换打破匀速感 | 能有效拉回走神的观众；但如果每几秒就惊乍换挡一次，整片会失去呼吸感，显得浮躁 |
| **顶点后干脆收束** | 核心认知闭合或核心爽点演完后，留一拍余韵即收；把力气省在最高潮那一下 | 高潮后再接一段"综上所述我们学到了三点"会让完播率在尾部跳水；只有面向收藏查阅的工具清单片才值得付尾部总结的代价 |

## 3. 给耳朵写的口播：人设、密度与音画关系

观众是在**听**一个人说话，不是在读一篇论文。写进 `script.json` 的台词如果像书面说明文，再好的 TTS 音色念出来也像机器播报。

### 说话姿态（Persona）与音色联动
动笔前在 `brief.md` 定下本片的说话姿态，再联动 `film-narration` 的 `voices.py` 选角与语气指令（`instruction`）：
- **拆解内幕的同行朋友**：用"你可能也遇到过""猫腻就在这儿"拉近距离，适合 KOL 观点、商业与技术内幕；代价是过于口语化会削弱严肃历史或官方发布的权威感。
- **克制冷静的观察者**：少用感叹词，靠具体动词和事实本身的张力说话，适合历史、纪录、硬核机制片；代价是如果画面本身也平淡，容易显得冷漠催眠。
- **直给解法的产品主理人**：短促、笃定、聚焦前后效率反差，适合产品发布与功能种草；代价是一旦掺入自夸形容词（"行业领先、极致赋能"），观众会立刻启动广告防御。

### 书面语转听觉语的四个杠杆
1. **短句与单向逻辑**：阅读时眼睛能往回扫长定语（"那个由十六户成都富商在真宗年间联合印制的纸券"），耳朵只能往前走。拆成顺着时间流动的短句（"真宗年间，成都十六户富商联手，印出了一张纸券"），写完自己出声顺读一遍，喘不上气的地方必改。
2. **听觉消歧**：把书面同音易混词换成耳朵一听就懂的词（少用单音节代词"其/彼/之"，注意专名与缩写的读音，易错读音提前写进 `script.json` 的 `pronunciationDict`）。
3. **数字与新概念预算**：每 30 秒真正要求观众记住的承重数字或陌生术语控制在 1–2 个以内；其余支撑性数字转化为体感对比（"不到三分之一""眨眼工夫"），避免听觉过载。
4. **合成前先做时长摸底**：写完初稿先跑 `python3 <film-narration>/scripts/_timing.py estimate <script.json 或片子目录>`，不花合成费就能估算每句和全片秒数。如果超出目标时长，在文字阶段删枝蔓，不要指望靠拉高 `speechRate` 硬塞——语速过快会吞掉停顿与重音，让观众来不及看清画面变化。

### 音画同构 vs 音画对位
- **音画同构**（画面直接演化旁白所说的状态变量）：认知负担最低，适合把复杂原理讲透（见 `references/mechanism.md`）；代价是一切都要对齐同一个变量时，幽默感与言外之意较少。
- **音画对位**（旁白说表面常识或克制陈述，画面亮出反差证据、荒诞后果或细节特写）：极具 KOL 个人风格与戏剧张力，适合观点片、吐槽拆解与案例反转；代价是声音与画面各自传递不同信息，节奏留白不够会让观众顾此失彼。
- 无论同构还是对位，都要警惕**字面配图病**（旁白念到"增长"弹一个箭头、念到"安全"弹一把锁）——那既不提供证明，也不制造张力，只是在消耗注意力。

## 4. 社交传播驱动力与营销转化弧线

### 三种互动驱动力（立项时选主攻项）
一支片子很难同时拿满转发、收藏和评论，主攻方向不同，脚本重心也不同：
- **转发驱动（社交货币 / 嘴替金句）**：观众转发往往不是因为片子"客观"，而是这支片子替他说出了某个洞察、品味或立场。脚本要在高潮或收尾处锤炼一句**无需上下文也能立住的凝练判断**；代价是若前面缺乏扎实证据铺垫，硬凹金句会显得空洞说教。
- **收藏驱动（结构化获得感）**：观众觉得"以后用得上"。适合给出清晰的判据表、三步排障法或选型坐标；代价是干货越密，越需要靠视觉分层减轻记忆压力。
- **评论驱动（认知分岔 / 留白提问）**：在结尾或关键权衡处抛出一个没有标准答案的真实两难（"换作是你，保吞吐还是保延迟？"）；代价是问题若太泛（"你怎么看？"）无人理睬，太偏激又会引来无效骂战。

### 丝滑产品与营销转化弧线
带商业转化或开源推广目标的片子，把产品当成**解决痛点后的必然答案**，比当成主角硬夸有效得多：
1. **具象摩擦开场**：直接演用户习以为常却极其低效的那个瞬间（不先报品牌名）。
2. **旧方案为什么卡壳**：用一两镜拆穿旧做法的结构性瓶颈，让受众觉得"原来不是我笨，是工具路子错了"。
3. **新范式 / 核心爽点实证（USP）**：只挑**最锋利的一个差异点**在画面上跑通前后对比（比如三步变一步、乱码瞬间对齐），让画面本身当证据，少念抽象形容词。
4. **低门槛下一步（CTA）**：顺着刚刚建立的爽感给出一个零摩擦动作（试跑一行命令、领模板、看实测对比），而不是生硬喊口号。需要测不同开场钩子或渠道转化语时，把钩子与 CTA 抽进 `content.json`（见 `<film-core>/references/content-json.md`），用同一套场景代码批量出变体。

## 5. 平台语境与画幅心理

画幅决定的不仅是构图比例，还有观众当时的观看姿态与界面遮挡环境：

| 语境 | 观看心理 | 脚本与版面取舍 |
|---|---|---|
| **`9x16` 竖版信息流**（抖音 / 视频号 / 小红书 / Shorts） | 单手刷屏、耐心极短、随时划走、常静音起播 | 开场钩子前置；画面底部约 18%–22% 会被平台文案/进度条遮挡，右侧中部有头像点赞栏，核心视觉与内嵌字幕重心宜放在中上部安全区；单屏字数宜少而大 |
| **`16x9` 横版主动点播**（B 站 / YouTube / 官网 / 发布会） | 看到标题封面主动点进、预期完整深度与空间感 | 允许更从容的铺垫、并排对照和宽画幅空间调度；如果照搬竖版短视频每两秒一惊一乍的催促腔，反而会破坏深度信任感 |
| **`1x1` / 跨平台同源多画幅** | 社媒信息流卡片、多渠道分发 | 用归一化比例布局（见 `<film-core>/references/layouts.md`），把承重元素留在各画幅交集中心，省去重排成本；代价是极端横竖空间的利用率不如单画幅定制 |
