# 讲法、长相与近作：防默认收敛的比选工具（按需）

目录：0. 采用外部设计 skill · 1. 讲法比选 · 2. 视觉方向与像素比稿 · 3. 近作对照

这是防止模型第一反应滑向平庸默认值的诊断工具，**不强制写长表**；最有效的方式依然是直接画 2–3 个差异巨大的单帧 `look/*.html` 在像素上判（见 `lookdev.md`）。

## 0. 采用外部设计 skill

可整体采用外部设计 skill（如 `frontend-design`、`canvas-design`、`algorithmic-art`、`theme-factory`）的方向，在 `docs/style_guide.md` 写明采用了谁的哪部分；技术接入仍守 `film-core/references/kernel.md`（CSS 动画设 `USES_WAAPI` + `currentTime`，字体随片打包）。

## 1. 讲法比选（防百科流水账）

容易写成“定义→历史→规则→总结”说明书时，先对比 2–3 种结构骨架（钩子与留存详见 `creator-playbook.md`）：

| 类 | 骨架 | 核心发力点 |
|---|---|---|
| 顺序 / 清单 | 定义、步骤依次展开 | 适合收藏查用；前 3 秒易划走 |
| 问题 / 悬念 | 抛具体反直觉现象，层层剥开 | 解谜瞬间 |
| 反转 / 破误区 | 立常识 → 证据推翻 | 认知翻转，转发/评论力强 |
| 跟随视角 | 跟一个具体对象走完全程 | 生死拐点，代入感强 |
| 终局前置 | 第 0 秒亮崩溃/反常结局，再回溯 | 开场抓人 |
| 痛点—爽点转化 | 具体摩擦 → 旧法瓶颈 → 实证 → CTA | 前后反差，适合产品种草 |
| 加码 / 预测互动 | 逐层加压至质变，或先押注再揭晓 | 质变/揭晓瞬间 |

两个快查问题：**高潮落在哪（闭环后能否利落收尾）？观众看完最可能复述或转发哪一句？**

## 2. 视觉方向与像素比稿

真正不同的视觉方向至少差**两个维度**：调子（明暗冷暖）、材质/媒介感（平涂/实物/3D/纸墨/网页 UI）、镜头视角、字的身份、主色承重；只换配色不算不同方向。

不要停留在纯文字比选——把最看好的 2–3 个方向（至少一个跳出第一反应）直接写成单帧 `look/*.html`，拼成 `out/lookdev.png` 在像素上看清：① 核心信息/情绪读不读得出；② 视觉焦点够不够有记忆点；③ 360px 手机宽下清晰度与形似风险。

## 3. 近作对照（按需）

担心和仓库已有片子撞脸时，跑 `node <film-story>/scripts/siblings.mjs --film <slug>` 打开 `out/siblings.png` 对照；决定拉开哪几个维度，或作为系列片有意沿用（重复本身没问题，无意识重复才需要防）。
