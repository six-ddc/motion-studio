# 机制判据与案例（适合原理/算法/物理科普片）

目录：1. 定义与适用边界 · 2. 三刀诊断 · 3. 四种非机制 · 4. 正反案例 · 5. 代价与常见分镜坑

## 1. 定义与适用边界

**机制 = 把主题的核心变量映射到一个连续变化的视觉变量上**（关掉旁白，单看画面也能看出它在如何演变）。
- **适合用**：抽象原理、算法协议、物理过程、金融清算等核心是一条因果规律的题目。
- **不必硬套**：人物故事、KOL 观点、产品发布会、多维盘点或情绪宣传片——强塞进单一连续数学变量会生硬枯燥，改用冲突弧线、前后反差实证或丰富网页/3D 视觉语言更合适（见 `SKILL.md` §2）。

## 2. 三刀诊断（防退回通用 PPT 容器）

1. **刀 1 · 换题测试**：把候选里的专有名词换成 `[X]`，套进「一道菜的做法 / 融资轮次 / 一个人的一天」——照样成立且理由全是“整齐、清楚、好排”，说明只是通用容器而非专属机制。
2. **刀 2 · 自演化**：规则定好后，后续镜头能否由同一规则自然推演？每镜另起炉灶、一次性变形或二值开关图标撑不起整片主梁。
3. **刀 3 · 音画咬合**：同构旁白离开画面就不完整，或对位旁白靠画面亮出反差证据；念百科定义+弹无关图标则是字面配图。

## 3. 四种“非机制”（可做局部辅助，不撑整片主梁）

| 类型 | 常见形态 | 怎么用 |
|---|---|---|
| **容器** | 网格、卡片列表、时间轴、柱状图、节点连线、分屏 | 承载辅助数据，不充当唯一主轴 |
| **装饰** | 有风格但无映射（水墨淡入、赛博卡片） | 属美术调性，不是机制 |
| **图标** | 锁、灯泡、齿轮、箭头 | 局部标注 |
| **一次性变形** | A 变成 B 演完即止 | 开场钩子或收尾 |

## 4. 正反案例

- **唐·兴衰**：✗ 108 坊网格逐格弹出 → ✓ 墨的浓度与完整度 = 国运，宫阙从墨里挖出。
- **交子**：✗ 地图打点扩散 → ✓ 价值 = 重力：铁钱压塌桌面，交子变重，超发后变轻飘散。
- **TLS 握手**：✗ 双竖线箭头时序图 → ✓ 安全状态 = 窃听者视角下明文可读度，建密后连字幕溶成乱码。
- **融资轮次**：✗ A/B/C 卡片弹入 → ✓ 所有权 = 守恒面积，每轮把创始人那块切薄。

## 5. 代价与常见分镜坑

选定前权衡代价：教科书比喻虽易懂但缺记忆点；非直观映射开头需花时间交代规则；依赖事实的映射须在 `facts.md` 有出处。
经典分镜翻车点（详见 `docs/verified/film-story.md`）：① 三元对称构图易触发人脸错视（形似风险）；② 按年份等物理量线性映射会压缩高潮（安史之乱只剩 0.111s，需给重要区间单独绑锚点）；③ 旁白断言状态时画面已归零（用 `claims` 校验整个念读区间）；④ 均匀尖刺轮廓被读成齿轮。
