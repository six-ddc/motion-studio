# 音效与音乐：来源与授权

**配乐是素材链里最容易出问题的一类**：常见情况是发布后被平台 Content ID 认领，收益被划走、片子被静音或下架，而手里没有可以申诉的凭据。**查证状态**：第 3 节的来源表沿用旧 `motion-assets` skill 的记录，**2026-10-21 未逐条复核原文**（标 ✔ 的除外）。

目录：1. 为什么配乐特别难 · 2. 用配乐前逐条回答 · 3. 来源（旧记录）· 4. 什么时候合成、什么时候用真素材 · 5. 环境声 / 底噪。转码（`media.mjs audio` → PCM WAV）见 SKILL.md；响度、ducking、合流参见 film-narration。

## 1. 为什么配乐特别难：一首曲子同时有三层

| 层 | 是什么 | 谁会来追究 |
|---|---|---|
| 作曲/词版权 | 旋律与歌词本身 | 版权协会、出版商。**翻唱或重新编曲仍受它约束** |
| 录音版权 | 这一版录音 | 唱片公司、平台 Content ID |
| 平台登记 | 作者把曲子登记进 Content ID、抖音等平台的识别库 | 系统自动认领，没有人工判断 |

"免版税 royalty-free"只表示**不按使用次数付版税**，既不表示免授权，也不表示没人登记过 Content ID。"YouTube 音频库可用"只说明在 YouTube 上可以用，**能不能在站外（B 站、抖音、广告投放）使用，要看那首曲子的条款**（旧 skill 列为待核）。

## 2. 用配乐前逐条回答

1. 授权是否覆盖**这个用途**？（个人、商用、广告投放、电视广播、游戏、App 内使用常常是不同的授权档位）
2. 授权是否覆盖**这个平台**？
3. 要不要署名？格式是什么？署在片尾还是简介里？
4. 这首曲子**有没有登记 Content ID**？（Pixabay 带盾牌图标的曲目可能被认领；Mixkit 的条款不允许使用者去注册 Content ID）
5. 有没有**可以保存的授权凭据**（下载证书、授权邮件、订阅期内的下载记录）？存进 `assets/_incoming/<来源>/`，并在台账里写明路径。
6. 对订阅制曲库要问：**订阅到期后，已发布的作品还受保护吗？** 条款没写清楚就按不受保护处理。

只要有一条答不上来，就不要用这首曲子。替代方案按代价从低到高依次是：不用配乐，改用合成的节奏音（参见 film-narration skill 的 sfx）；CC0 曲目；明确为 CC BY 的曲目并署名；付费授权并保存凭据。

## 4. 什么时候合成、什么时候用真素材（合成怎么做参见 film-narration 的 `sfx`）

- **合成就够用的**：whoosh、低频 thump、tick、UI 提示音、节拍音。听众不会追究这些声音"是不是真的"，合成没有任何授权风险，还能按 t 精确摆放。
- **应该找真实素材的**：有材质感的 Foley（纸、布、玻璃、水）、环境声、人声反应。合成版本会被听出来，听出来会影响片子时就该用真素材。
- **配乐**：基本不合成；找不到授权清晰的曲子就不用配乐。

## 5. 环境声 / 底噪（路面、风、人群、机房……）

环境声是一层"连续、不抢戏"的声音底（胎噪、雨声、车流）。它和 whoosh、tick 不同，**听众能听出真假**，不过在混音里通常压得很低。两条路各有代价：

| | 自制（ffmpeg 彩色噪声加滤波） | 录音素材（CC0 等） |
|---|---|---|
| 授权 | 没有风险，台账里写"自制"并附上命令 | 要逐条查，见下表 |
| 确定性 | 固定 `seed` 时**可以字节级复现**（同一条命令运行两次 md5 相同） | 文件固定下来即可复现 |
| 可控性 | 时长、起伏、频段都是参数，可以跟随画面里的速度曲线变化 | 只能剪辑、循环、调 EQ；循环点要藏好 |
| 听感 | **听起来像风或空调，不像路面**：缺少胎纹带来的周期性、远近车辆的多普勒效应，以及偶发事件（颠簸、喇叭） | 一听就是"那个地方" |
| 什么时候值得 | 底噪压得很低、画面风格本身偏抽象或图示化，或者授权上不能冒任何风险 | 底噪是情绪的一部分，或者画面是写实风格 |

### 自制配方（手法，不是默认值——频段和起伏按本片调）

```bash
# 胎噪：粉噪声带通在 300–2500 Hz，900 Hz 附近抬 6 dB；滚动：棕噪声低通 120 Hz；整体 0.35 Hz 慢起伏
ffmpeg -f lavfi -i "anoisesrc=color=pink:amplitude=0.6:seed=11:duration=24" \
       -f lavfi -i "anoisesrc=color=brown:amplitude=0.6:seed=12:duration=24" \
  -filter_complex "[0]highpass=f=300,lowpass=f=2500,equalizer=f=900:t=q:w=1:g=6,volume=0.5[tire];\
[1]lowpass=f=120,highpass=f=30,volume=0.9[rumble];\
[tire][rumble]amix=inputs=2:normalize=0,tremolo=f=0.35:d=0.25,afade=t=in:d=1.5,afade=t=out:st=22.5:d=1.5" \
  -ar 48000 -ac 2 -c:a pcm_s16le assets/audio/road-bed.wav
```

- **为什么分两层**：单层棕噪声经低通（380 Hz）后，频谱质心约 320 Hz，听起来更接近风声或远处的雷声；胎噪有相当一部分能量分布在几百 Hz 到 1-2 kHz 之间，两层配方的质心约 1460 Hz。这只是频谱上的数字，还没有经过人耳确认"像路面"。
- **跟随画面变化**：要让底噪随车速变化，可以把 `volume`/`lowpass` 的参数写成随时间变化的表达式（ffmpeg 的 `volume=eval=frame:volume='…t…'`），或者分段生成后再交叉淡化。音效如何按旁白时间摆放，参见 film-narration skill。
- **seed 要写进台账**：换一个 seed 就是另一段噪声。ffmpeg 换版本后是否仍能字节一致，还没有测过。
