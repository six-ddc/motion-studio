# 音效与音乐：来源与取舍

目录：1. 来源 · 2. 配乐：现成曲子还是合成 · 3. 什么时候合成、什么时候用真素材 · 4. 环境声 / 底噪。转码（`media.mjs audio` → PCM WAV）见 SKILL.md；响度、ducking、合流参见 film-narration。

## 1. 来源

| 源 | 类型 | 说明 |
|---|---|---|
| Freesound | 音效、环境声 | 量最大，质量参差，逐条试听；可按时长、采样率、文件格式筛选 |
| Pixabay | 音乐、音效 | 网页直接下载 mp3 |
| Mixkit | 音乐、音效 | 按情绪和类别分好，适合快速找 |
| Incompetech（Kevin MacLeod） | 音乐 | 曲库老而全，按风格、情绪、速度可查 |
| YouTube 音频库 | 音乐、音效 | 需要登录 YouTube 工作室下载 |
| Kenney | 音效 | 游戏向的 UI、打击、拾取音效包，整包下载 |
| Sonniss GDC 免费包 | 音效、环境声 | 每年发布的专业录音包，体积大（几十 GB），多为高采样率 WAV |
| BBC Sound Effects | 音效、环境声 | 大量实地录音，环境声品类尤其全 |

下载时按硬约束 2 放进 `assets/_incoming/<来源>/`，用 `media.mjs audio` 转成统一采样率的 WAV 再用。

## 2. 配乐：现成曲子还是合成

- **现成曲子**：成曲完整、有编曲层次，代码合成很难达到。代价是曲子的结构是固定的，画面要去迁就它的段落和节拍（先定曲，再用 film-narration 的节拍栅格把事件挂上去）；剪短时要找好剪点或做淡出。热门曲目可能被平台识别后静音或限流。
- **代码合成**（film-narration 的 `music.py`）：段落、速度、长度都跟着片子走，可以确定性复现。代价是音色和编曲的上限有限，适合节奏型、电子、氛围类的底。
- **不用配乐**：只用合成的节奏音或音效（参见 film-narration skill 的 sfx），也是一种选择，适合信息密度高、旁白主导的片子。

## 3. 什么时候合成、什么时候用真素材（合成怎么做参见 film-narration 的 `sfx`）

- **合成就够用的**：whoosh、低频 thump、tick、UI 提示音、节拍音。听众不会追究这些声音"是不是真的"，合成还能按 t 精确摆放。
- **应该找真实素材的**：有材质感的 Foley（纸、布、玻璃、水）、环境声、人声反应。合成版本会被听出来，听出来会影响片子时就该用真素材。
- **配乐**：一般用现成曲子或 `music.py`，取舍见第 2 节。

## 4. 环境声 / 底噪（路面、风、人群、机房……）

环境声是一层"连续、不抢戏"的声音底（胎噪、雨声、车流）。它和 whoosh、tick 不同，**听众能听出真假**，不过在混音里通常压得很低。两条路各有代价：

| | 自制（ffmpeg 彩色噪声加滤波） | 录音素材 |
|---|---|---|
| 确定性 | 固定 `seed` 时**可以字节级复现**（同一条命令运行两次 md5 相同） | 文件固定下来即可复现 |
| 可控性 | 时长、起伏、频段都是参数，可以跟随画面里的速度曲线变化 | 只能剪辑、循环、调 EQ；循环点要藏好 |
| 听感 | **听起来像风或空调，不像路面**：缺少胎纹带来的周期性、远近车辆的多普勒效应，以及偶发事件（颠簸、喇叭） | 一听就是"那个地方" |
| 什么时候值得 | 底噪压得很低、画面风格本身偏抽象或图示化 | 底噪是情绪的一部分，或者画面是写实风格 |

### 自制配方（手法，不是默认值——频段和起伏按本片调）

```bash
# 胎噪：粉噪声带通在 300–2500 Hz，900 Hz 附近抬 6 dB；滚动：棕噪声低通 120 Hz；整体 0.35 Hz 慢起伏
ffmpeg -f lavfi -i "anoisesrc=color=pink:amplitude=0.6:seed=11:duration=24" \
       -f lavfi -i "anoisesrc=color=brown:amplitude=0.6:seed=12:duration=24" \
  -filter_complex "[0]highpass=f=300,lowpass=f=2500,equalizer=f=900:t=q:w=1:g=6,volume=0.5[tire];\
[1]lowpass=f=120,highpass=f=30,volume=0.9[rumble];\
[tire][rumble]amix=inputs=2:normalize=0,tremolo=f=0.35:d=0.25,afade=t=in:d=1.5,afade=t=out:st=22.5:d=1.5" \
  -ar 48000 -ac 2 -c:a pcm_s16le assets/audio/road-bed.wav
```

- **为什么分两层**：单层棕噪声经低通（380 Hz）后，频谱质心约 320 Hz，听起来更接近风声或远处的雷声；胎噪有相当一部分能量分布在几百 Hz 到 1-2 kHz 之间，两层配方的质心约 1460 Hz。这只是频谱上的数字，还没有经过人耳确认"像路面"。
- **跟随画面变化**：要让底噪随车速变化，可以把 `volume`/`lowpass` 的参数写成随时间变化的表达式（ffmpeg 的 `volume=eval=frame:volume='…t…'`），或者分段生成后再交叉淡化。音效如何按旁白时间摆放，参见 film-narration skill。
- **seed 要记下来**（写在生成命令里，命令随片子保存）：换一个 seed 就是另一段噪声。ffmpeg 换版本后是否仍能字节一致，还没有测过。

录音素材从第 1 节的来源里找，Freesound、Sonniss、BBC Sound Effects 的环境声品类最全。
