# 三维世界：天空、雾、软阴影、表面、湿地面、火花与烟

目录：1 天、雾、反射同源 · 2 天空与云 · 3 解析高度雾与软阴影 · 4 表面分层与风化 · 5 破损贴图烘焙 · 6 湿地面与平面反射 · 7 火花、烟、火 · 8 代价与局限

都是可选能力，套件不提供实现；本页给原理、在 `seek(t)` 下的难点、本仓库实测代价和坑。往材质里注入代码的通用做法见 three.md §5，色值、尺度、幅度全部由本片 style_guide 决定。

## 1. 天、雾、反射同源

天空、雾色、环境反射、环境光如果各调各的，反射与背景的光向、色相就对不上，读起来像拼贴。做法：片子写**一份**纯数据的光照预设（太阳方向/颜色/强度、天顶色、向阳/背阳地平线色、地面色、雾色），由它派生：
- 平行光（方向、颜色、强度）；
- 天空着色器的 uniform，以及一段 GLSL 函数 `horizonColor(worldDir)` / `skyGradient(worldDir)`，给雾、体积雾、反射复用；
- 环境反射：加载期用同一个天空着色器拍一张 cube，过 `PMREMGenerator` 得到粗糙度 mip 链，设为 `scene.environment`。拍的时候不画日盘、钳 HDR 上限，太阳只由平行光负责，否则镜面上会出现两个太阳。

天空的形状：地平线色按与太阳的方位夹角插值（`pow(max(cos Δφ,0), azimuthPower)` 让向阳色集中在太阳方位），向天顶、向地面各用一个高度（sin 仰角）做平滑过渡；日晕是 1–4 层 `pow(max(dot(dir, sun),0), n)·w` 叠加（只有一层宽晕的代价是整片天发白）；日盘按视直径做 smoothstep（真实太阳 ≈ 0.53°）。

难点：云在动而环境贴图是加载期拍的，镜面近景会有反射误差；值得的话按镜头预拍几张，paint 里按 t 选（选择是 t 的函数，不是"上一帧拍的"）。环境光和 PMREM 叠加会抬高整体照明，二选一或减弱一方。

## 2. 天空与云

平面投影云层（不是三维体积步进）：视线与高度为 altitude 的平面求交，`uv = dir.xz / (dir.y + horizonLift) · altitude / featureSize + wind·t/featureSize`。
- 风的偏移在 JS 里用 double 算好再传，长片才不抖（SKILL.md 硬约束 4）。
- 覆盖率：`smoothstep(1−coverage−softness, 1−coverage+softness, fbm)`；softness 小边缘硬、运动时闪。
- 体积感来自 domain warp 和**向光密度差**：在 uv 朝太阳方向偏一点再采一次密度，差值当自阴影（relief），亮边（rim）来自逆光处的薄边。每多一步阴影采样就重算一组 fbm，软件渲染明显变慢。
- 近地平线：`horizonLift` 太小云压成一条密带，并且高频走样；按距离向地平线色淡化（空气透视）。
- 噪声用加载期按种子生成的纹理比实时 fbm 便宜；云在太阳周围开洞、对日盘的遮挡（veil）都是构图选择。
- 可用的库（如需）：three examples/jsm 的 `Sky`（Preetham 解析天空，只有天没有云）、`Water`；真体积云要三维步进，SwiftShader 下极贵。

## 3. 解析高度雾与软阴影

**高度雾**：密度 `ρ(y) = d·e^{−(y−y0)/H}`，沿视线的光学深度有闭式积分：`τ = d·H·e^{−(oy−y0)/H}·(1 − e^{−dir.y·L/H}) / dir.y`（dir.y→0 时取极限 `d·e^{…}·L`）。`fog = min(1−e^{−τ}, maxOpacity)`，颜色取该方向的 `horizonColor`，再加一个向阳瓣 `pow(dot(dir,sun), p)·s·sunColor`。在色调映射之前融进材质颜色（注入 `<fog_fragment>`）。没有光柱遮挡；要有阴影的介质用后期体积雾（three-post.md §2）。

**PCSS 软阴影**（接触处硬、远处软）：`BasicShadowMap` 下在材质里自写阴影查询：① 遮挡搜索：在半径 R 内取 N 个深度样本求平均遮挡深度 d_b；② 半影宽度 `w = (d_r − d_b)·tan(太阳视角)/d_b`；③ 以 w 为半径 PCF。每个受影像素 `blockerSamples + samples` 次深度读取。样本圈用 IGN 旋转（静态、屏幕坐标的函数）防规则条纹，软影仍可能有颗粒。同一材质的阴影共用一个视锥尺寸；接收面加梯度偏移防痤疮。

**前景层**：把专用材质的深度压进 [0, ε]（改 `gl_FragDepth` 或投影矩阵）让手持道具永远在最前且仍写深度；后期要按同一个 ε 排除它（three-post.md §5）。

## 4. 表面分层与风化

**按成因分层**：材料本体、湿润、积垢、磨损、尺度分开写进不同通道。一张均匀噪声同时染色和改粗糙度会掩盖因果；**粗糙度变化**决定高光像不像塑料，只加颜色细节受光时仍是一块均匀亮斑。低频成簇噪声管"哪里发生"，细噪声管"局部是什么"；连续斜坡的代价是多算一段过渡，硬阈值的代价是贴纸般的分界。

| 层 | 原理 | 坑 |
|---|---|---|
| 宏观变化 | 两层 3D 值噪声调反照率（相对）和粗糙度（绝对） | world 空间会在移动物体上"游移"；动的物体用 object 空间 |
| 积垢 | AO（aoMap 或顶点色）× 噪声，过 ramp，压暗加糙 | AO 只能提示遮蔽，推不出真正的积垢过程 |
| 湿润 | 全局湿度 level：压暗、乘粗糙度（湿后更光滑）、增饱和、压平法线；朝上的面比竖面湿；竖面加按两轴频率比拉长的流痕；低处溅湿带 | 封闭表面主要调粗糙度，多孔表面主要压暗；它不是液体仿真 |
| 水珠 | 程序化圆点改法线和粗糙度；按像素足迹（`fwidth`）超过阈值就不画 | 不消退的亚像素水珠会闪；水珠不改剪影 |
| 三平面映射 | 三个轴向各采一次，按 `pow(|n|, sharpness)` 混合；切线空间法线要做正确的方向混合 | 贴图读取近 3 倍；贴图要 RepeatWrapping |
| 抗闪烁 | Toksvig：法线贴图 mip 后长度变短 → 加大粗糙度；给粗糙度设下限、高光设上限 | 也会钝化刻意锋利的高光 |

湿度、尺度这类会动画的值在 paint 里每帧写（放在 `material.uniforms` 上舞台会复位，放在注入的共享对象上要自己写满）。频率参数即使加载期相等也分别求值，避免改了一个却复用同一遮罩。

**加载期顶点色风化**：先按最大边长细分几何（重心网格保留法线/UV/颜色），再按世界坐标烘进顶点色：低频斑驳、朝下/侧面亮度倍率（半球近似）、离地接触污垢带、用焊接邻接估计凹凸（凹处积垢、凸棱提亮）、凹处成簇锈色。是廉价的 AO/接触阴影近似，不跟踪物体间遮挡、物体移动不重算；大三角形会把窄污垢带抹成整面渐变，所以接触带跨距不足时要细分（设三角形上限防几何爆增）。渲染时只是一次顶点色乘法。

## 5. 破损贴图烘焙

漆面破损：破损度 `d = sat((amount − (簇·(1−detail) + 细·detail)) / softness)`，按 stages 依次露出底漆 → 锈 → 金属，**每层同时换颜色、粗糙度、金属度和高度**（只换颜色像印花）。从高度场用米制间距差分出法线（换分辨率不改凹凸强度），输出共享的 ORM（R=AO、G=粗糙度、B=金属度）。
- 反照率按 sRGB 编码存 8 位、标 `SRGBColorSpace`：线性 8 位存暗部会出色带。
- CPU 烘焙时间 ∝ size² × 层数；GPU 烘焙用一个 RenderTarget 跑一遍全屏着色器，烘完恢复 renderer 的目标、面、mip、viewport、scissor。
- 都在加载期做，seek 里只引用。

## 6. 湿地面与平面反射

**一张覆盖全场的唯一遮罩**（RGBA = 高度 / 潮湿 / 油污 / 磨损，米制 bounds），加两个不整比尺度的细节噪声防重复。湿润按水位与高度差连续过渡：积水 → 浸湿 → 潮湿 → 干燥，四档粗糙度（积水档接近镜面）乘到材质粗糙度上。区域外按"最高、干、无油"处理并在边缘渐变。高度编 8 位时提分辨率不提高度位深。

**闭式雨滴涟漪**：每层按 cell 米分格，每格每周期 `floor(t·rate·抖动)` 换一滴（位置、大小、强度由 `hash(格, 周期号)` 给），寿命 = 小数部分；环剖面是高斯导数，宽度随寿命长大，振幅 (1−寿命)² 衰减；环半径 ≤ 0.45 格让环整个落在格内，就没有格缝。几层旋转网格叠加打破对齐。远处淡出：环小于一像素时不淡出就闪烁。它不是水动力模拟。

**当帧平面反射**：镜像相机（相机关于平面 y=planeY 镜像）+ 斜近平面裁剪（Lengyel 的 oblique near plane，防平面下的几何漏进反射），渲到一张 RT，采集线性 HDR、按粗糙度取 mip，替换环境镜面输入（保留菲涅耳）。多一次场景绘制，代价按反射 RT 像素数；只支持透视相机、单平面、不递归；能看见画外物体（不是 SSR）。
- **必须在 paint 里、相机与物体按 t 设好之后渲染**。"画完这一帧再更新、下一帧再用"会读到上一帧的 RT：`reset:true` 时反射矩阵被还原到 freeze 值，过期反射整个落到画外（看起来是"反射消失"）；`reset:false` 时门 1a/2 红（本仓库阴性对照实测）。
- **低机位倒影的几何**：镜面里是镜像相机看到的东西——近地平线的天（低仰角的日/月盘会被镜成地上一个亮斑）、物体的底面与背面；贴地物体的倒影常被自己的底座挡掉。写镜头前先算：把目标点关于平面镜像，投影到屏幕，就知道倒影落在哪、对应地面哪一点（再拿去对积水遮罩）。
- **排查说不清来源的亮斑**：逐个关掉每盏灯、环境/IBL、日盘、日晕、天空、雾、平面反射、涟漪、自发光、加法粒子、泛光，比较区域亮度差。在场景里留一组调试开关（URL 参数）就能做；每个源多渲一帧。
- 可用的库（如需）：three examples/jsm 的 `Reflector`（平面反射，内部在 `onBeforeRender` 里渲，要确认它在本帧相机设好之后才触发）。

## 7. 火花、烟、火

**事件表 + 闭式阻力弹道**：每个事件 `{t0, life, origin, velocity, size, seed}`，粒子状态是 age = t − t0 的闭式函数：`v' = g − c·v` 的解析解 `p = p0 + v0·f + g·(a−f)/c`，`f = (1−e^{−c·a})/c`（c→0 退化为抛物线）。CPU 侧用同一条公式拿位置（锚点、碰撞判定）。碰撞与力场积分走 film-physics。
- **火花**：实例化相机朝向四边形，沿屏幕空间速度拉长（拖影长度 = 速度 × 若干秒）。像素尺寸设下限并按面积比降 alpha，远处才不闪。相机速度模糊交给子帧平均。
- **受光烟**：加载期按种子生成烟团图集（每格存法线 xy、厚度、alpha，同一团随寿命侵蚀），着色时用包裹漫反射 + 逆光近似；格边留透明、不生成 mip。寿命末尺寸倍数大 = 散得开，淡入短 = 出现时硬跳。
- **火焰**：同一图集的厚度映射到温度色，加法混合（只会变亮、不能遮挡）。
- **深度软交界**：用同一相机**当帧**不含粒子的深度纹理，按 `sat((sceneDepth − particleDepth)/distance)` 淡 alpha，解决烟切地面的硬边。用上一帧的深度会破坏乱序一致；反射副相机不用它。
- 实例不逐粒深度排序：重叠烟团的顺序靠加载期分组或降低不透明度。
- 跟随相机的周期雨盒：`p = box.min + mod(p0 + v·t − 相机偏移, box.size)`，闭式、无缝。

## 8. 代价与局限

1080×1920，seek + 同步读回，5 帧中位数（ms；并发开发下有噪声，微小差异不作结论）：

| 场景 | SwiftShader | GPU |
|---|---:|---:|
| 程序化天空 + 云 + 球 + PCSS（整场景） | 118.8 | 1.7 |
| 128 面环境捕获（加载期一次，含首次编译） | 451.5 | 28.2 |
| 大地面，裸材质 | 109.9 | 1.5 |
| 同上 + 抗闪烁 / 宏观 / 积垢 | 111.5 / 109.9 / 111.1 | 1.5 / 1.7 / 1.7 |
| 同上 + 湿润 | 115.2 | 2.2 |
| 同上 + 三平面 | 138.8 | 1.3 |
| 全开 | 150.6 | 2.1 |

- 顶点色风化只占加载时间。非均匀缩放、蒙皮、顶点位移下的表面层没有专门验证。
- 本仓库对这些做法的局部验证不等于整片观感已验收；它们都没有交付门，跨帧状态靠 seamcheck 门 2 / 门 4 抓。
